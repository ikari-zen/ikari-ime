# フェーズ3 辞書に1語で入っている熟語と、同音の語＋1文字の接辞の分割（B19。ADR 0011 のスパイク）

- 実行日: 2026-10-14 / 基準は main f4fce68 の辞書（`data/build/dict` と同じ sha256 を、スパイクの builder で作り直して確かめた）/ release ビルド / macOS
- 辞書はスクラッチの場所に作った（共有の `data/build/dict` は変えていない）。CLI と eval は `--user-dir` に空のディレクトリを渡した
- スパイクのコード（`dict-builder` に、語ごとの加算をファイルから足す口。`core/src/lattice.rs` に辺の加算）はコミットしていない
- LM は `~/Library/Application Support/ikari-ime/models/zenz-v3.2-small-Q5_K_M.gguf`（読むだけ）

## 1. 現象と原因（測った値）

ユーザーの報告（2026-10-14）: けいたいそかいせき → 携帯素解析（期待 形態素解析）。

経路のコストは、Sudachi の lex.csv・matrix.def と chiVe の順位から計算し直した値が `ikari --format tsv` の値と一致することを確かめてから分解した（文脈なし、LM なし。Ranker の寄与は 0 で、score = 経路のコスト）。

| 経路 | BOS | 語1 | 連接 | 語2 | 連接 | 解析 | EOS | 合計 |
| --- | ---: | --- | ---: | --- | ---: | --- | ---: | ---: |
| 携帯 + 素(接尾辞) + 解析（1位） | 259 | 携帯 6507 + lemma_rank 427 | **-3669** | 素 8082 + 1209 | 1205 | 6516 + 1098 | -1334 | **20300** |
| 形態 + 素(接尾辞) + 解析（5位） | 447 | 形態 7203 + 1164 | -2620 | 素 8082 + 1209 | 1205 | 6516 + 1098 | -1334 | 22970 |
| 形態素（1語）+ 解析 | 447 | 形態素 12625 + **3843** | ― | ― | 1205 | 6516 + 1098 | -1334 | 24400 |

- 携帯 と 形態 の差 2670 の内訳: 語のコスト 696、lemma_rank 737（携帯 1633 位、形態 3817 位）、BOS の連接 188、**名詞 → 接尾辞 素 の連接 1049**（携帯 は サ変可能 で -3669、形態 は 一般 で -2620）。Sudachi の解析用の値で、どちらの語が 素 に付くかの意味は持っていない。
- 1語の 形態素 は、語のコスト 12625 に lemma_rank 3843（chiVe 83455 位）が乗り、`frequent_compound`（4万位まで）の加点が届かない。分割より 4100 高い。
- 形態素 の右ID（5774）は接尾辞 素 と同じなので、解析 への連接は分割と変わらない。差は語のコストとポリシーの加算だけ。
- LM（zenz）: 締め切りを 2000ms にすると、main でも 形態素解析 が1位になる（LM の加点の上限 6000 > 差 2670）。既定の締め切り（読み 9 文字で 54ms）では 携帯素解析 のまま（実機の報告と一致）。文脈 自然言語処理では、 があると既定の締め切りでも 形態素解析 になる。
- Full 版（SudachiDict の notcore_lex.csv、20260723）: 形態素解析（コスト 20326）と 効果測定（14242）は Full にある。しかし どちらも chiVe の語彙にないので lemma_rank が +5227 乗り、経路は 24666 で 携帯素解析（20300）に負ける。Full の辞書（同じポリシー）で CLI を流しても1位は 携帯素解析、効果測定 も3位のまま。**辞書を Full にしても、この問題は直らない。**

## 2. 同じ型の誤りの広さ（辞書から機械的に探した）

条件: Sudachi Core の 名詞,普通名詞 で、表記が lemma と同じ、漢字だけの3文字以上の語 W のうち、読みが「漢字を含む名詞の読み + 1文字の接尾辞か接頭辞の読み」に分けられ、その分割のうち **W と違う表記の頭（同音の語）+ 接辞** の経路（BOS と EOS を含む）が W より安いもの。

- **3457 語**（接尾 2623、接頭 834）。chiVe の順位で 4万〜10万位が 635、10万〜20万位が 654、20万位より下が 668、chiVe にないものが 1500。
- 全件を期待 W のセットにして流すと、main の1位は **67 / 3457**。
- 例（W / 1位の分割）: 機械化 / 機会化、正当性 / 正答性、嗜好品 / 施行品、注射器 / 駐車器、地政学 / 知性学、懐疑的 / 会議的、海兵隊 / 開閉隊、非対称 / 非対象、抽象化 / 中傷化、恒常性 / 向上性、敗血症 / 排血症、帰納法 / 機能法、母集団 / 募集団、拡声器 / 覚醒器、形態素 / 携帯素。
- 逆向き（W にしてはいけない）: 今の1位が chiVe で W より上位の表記であるもの 139 件（そうしき → 葬式（W 総指揮）、しりょうかん → 資料館（W 史料館）、うちゅうせん → 宇宙船（W 宇宙線）、きせいちゅう → 寄生虫（W 帰省中）、じゅけんしゃ → 受験者（W 受検者））。これを否定のセットにした。

評価セット: 上の 3457 件（mined、仮）と 139 件（neg、仮）はスクラッチで使い、人が選んだ 99 件を `eval/sets/compound-affix.tsv` にした（熟語 61 + ユーザーの報告 3、否定 35）。

## 5. 推奨案 A3 で直らないもの

- compound-affix の 2 件: しようせい 脂溶性（使用性 との差。脂溶性 は2位）、きかくか 規格化（企画課。同じ読みの 企画課 が chiVe で上位なので守りで外れる）。
- chiVe にない熟語（1500 件のうち多く）。上限なしにすると こう修正する → 高修正する が崩れる。
- 辞書にない熟語（効果測定、変数名、範囲外、日本語版）。B17 の 編数名・班以外・日本語＋ばん はこの規則の範囲外（§6）。

## 7. 再現

```sh

ikari --dict <dict> --user-dir <空> -n 10 --format tsv --segments けいたいそかいせき
ikari-eval --dict <dict> --ranker full --set eval/sets/compound-affix.tsv --out-cases <out>
ikari-eval --dict <dict> --ranker full --set eval/sets/compound-affix.tsv --lm <gguf> --lm-budget-ms 2000 --lm-deadline-ms 2000
```

案 A の辞書は、`dict-builder` の `Policy::evaluate` に「表記と読みの組ごとの加算をファイルから読む」一時的な口を足して作った（加点する語の一覧はスクラッチの Python で作った）。本実装では §3 の A3 の条件を `is_frequent_compound` に書く（ADR 0011 §3）。
