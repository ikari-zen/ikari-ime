### 2.1 cold の外れ値は、モデルの読み込み直後だけ
- LM ありの構成で cold が 30ms を超えたのは、**どれも先頭の2〜3件**（モデルの読み込みと Metal の初期化の最中）だった。
  - 待ち時間の上限が 30ms なのに、変換1回が 35〜41ms かかった。上限を長くした構成では最悪 72〜92ms。
  - これらのケースは warm でも 0.1ms 前後で返っており、**LM の結果は一度も使われていない**（処理中の同じ要求を重ねて送らない経路で、時間切れとして戻っている）。
- 先頭3件を除いた値は次のとおり。

| 構成 | cold p50 / p99 / 最悪（先頭3件を除く） | ケースごとの warm p99 の p99 / 最悪 |
|---|---|---|
| R4（doc + xsmall） | 6.9 / 12.7 / 15.5 | 11.7 / 11.8 |
| R5（doc + small） | 17.0 / 21.9 / 40.1 | 21.9 / 23.1 |
| R6（topic + small） | 17.0 / 21.2 / 21.6 | 23.6 / 25.4 |
| R6x（topic + xsmall） | 7.0 / 11.0 / 11.1 | 12.3 / 12.9 |

**短い読みでは、xsmall は p99 約 11ms で NFR-02（16ms）に収まる。small は p99 約 21ms で、NFR-02 は超えるが NFR-04（30ms）には収まる。** 待ち時間を延ばしても ext の正解率は変わらない（時間切れが読み込み直後の数件しかないため）。

### 2.3 否定ケースの回帰（Topic が文法を覆す）
- **`ext-neg-10`（サーバーを再起動 + しよう → しよう）は、R2 では1位、R3 と full では2位（1位が「使用」）。**
- LM ありの構成（R4〜R6x）では1位に戻る。
- IT の話題（サーバー、再起動）が「使用」（内容語）に加点して、LeftContext で上げた意志形を覆している。spec の「プロファイル」節が警告している型（話題で文法を覆す）で、Topic の既定値の変更（`min_content` 1、`weight` 10000）で起きた。dev（17/17）では見えなかった。

### 2.4 R3 → R6 で残る失敗の型（抜粋、`ikari-eval compare`）
- 助詞で始まる分割が上に来る: `は借る`（はかる）、`今日そう`（きょうそう）
- 頻度の高い同音語に寄る: 使用 / 仕様、時期 / 次期、回答 / 解答
- R3 → R6 で悪化した3件: 量る → 計る、試用 → 使用（2件）

## 4. LM の段階的な使い方のシミュレーション

### 4.1 方法
- CLI（`ikari --ranker full --profile none --format tsv -n 50`、空の一時ユーザーディレクトリ）を、各ケースについて LM なし、xsmall、small の3段で実行し、候補とスコアを集めた。
- LM の待ち時間は 3000ms にして、時間切れの影響を除いた（各段の「順位付けの質」だけを見るため）。
- 前段の1位と2位のスコア差（margin）が閾値 T 未満のときだけ次段の結果を使う、として合成した。
- **単段の正解率は eval と一致した**（ext 58.6 / 71.3 / 76.2%、AJIMEE 21.0 / 45.0 / 51.0%）。合成の前提は妥当。
- スクリプトはリポジトリに入れていない（作業ディレクトリの `cascade_collect.py`、`cascade_eval.py`。方法は上記のとおり）。

### 4.5 読み取れること
- **短い読み（ext）では、「迷ったときだけ LM」を使っても得が小さい。** LM なし → small で 30% の呼び出しを省くと −0.5 ポイント。xsmall → small の順に呼ぶ案は、半分のケースで xsmall と small を直列に呼ぶので、small を単独で使うより遅くなる（約 24ms 対 17ms）。正解率も small 単独を超えない。
- **長い読み（AJIMEE）では、xsmall → small（T=1000）が効率的。** small を 26.5% のケースだけ呼んで 49.0%（small 単独は 51.0%）。
- 「LM なしで迷ったときだけ LM」は、長文では大きく落ちる（T=1000 で 46.0%）。LM なしの margin は、長文の誤りをよく検出できない。

## 5. 再現手順

```

$E $AJ  --ranker topic --lm $L --lm-budget-ms 300 --out-cases aj-R6-b300.tsv
```
