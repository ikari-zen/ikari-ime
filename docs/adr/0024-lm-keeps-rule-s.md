# ADR 0024: LM が規則 S を覆さない（B40）。サ変でない名詞＋する を守った1位を、LM の後の最後の段で戻す

- 状態: 承認（2026-10-16。ユーザーが「Aで進めて」と決定）。実装済み
- 日付: 2026-10-16
- 対象: `CompositeRanker` の最後の段（LM の後）に、規則 S が守った1位を LM が覆したら戻す段を1つ足す。規則 S の判定は `core/src/lattice.rs` の品詞の分類を再利用する。辞書、LM、学習、規則 S の値（+3000）、proto・殻・engine は変えない
- 前提: main = 5656898。[ADR 0016](0016-rare-homophones.md)（規則 S）、[ADR 0003](0003-topic-ranker-decision.md) §2.1（Zenz は最後に置き、Guard で制限しない）、[ADR 0020](0020-english-spelling-first-candidate.md)（LM の後の最後の段の前例）、[ADR 0021](0021-lm-lookahead.md)（LM が付く変換が増える）
- タスク: docs/tasks.md B40

---

## 1. 問題

LM（zenz small）を付けると、LM なしで正解だった入力が不正解になる件が 33 件ある。そのうち 4 件は、規則 S（サ変でない名詞＋する の辺に +3000。ADR 0016）の効果を LM が上回って覆したもの。

| 入力 | 期待（LM なし） | LM ありの1位 |
| --- | --- | --- |
| げんきんする | 厳禁する | 現金する |
| てんじょうする | 添乗する | 天井する |
| じたくする | 支度する | 自宅する |
| ずしする | 図示する | 寿司する |

いずれも rare-homophones セット。LM の1位は 名詞,普通名詞,一般 ＋ サ行変格の する の分割になる。LM の入力は読みと文脈の文字列で、「名詞＋する は不自然」という辞書側の知識（連接表の区別を規則 S が強めたもの）を持たない。ADR 0003 §2.1 は LM を Guard の対象外にして最終的な順位を決めさせたので、規則 S の効果も LM に覆される。

## 2. 決定

**LM は、規則 S が効いて守られていた1位を覆さない。** LM を含めた並びの1位が 規則 S の辺（サ変でない名詞 → する・す）を含み、LM の前の並び（Guard のあと）の1位がそれを含まないとき、LM の前の1位を1位に戻す。

- 「候補は辞書から作り、LM は並べ替えにだけ使う」は変えない。候補の追加も削除もしない。LM は2位以下の並べ替えと、規則 S と関係のない1位の変更を、今までどおり行う。
- **ADR 0003 §2.1 の「Guard で制限しない」を、この1点で改める。** ほかの LM の変更（文法候補、内容語、学習）は今までどおり制限しない。
- 規則 S を止めた（`lattice.noun_suru.penalty = 0`）ときは、この段も働かない。

## 3. 仕組み

- **置き場所**: `CompositeRanker::rank` の中、LM の後。[ADR 0020](0020-english-spelling-first-candidate.md) の英字の繰り上げ（`english_first`）と同じ最後の段の仲間。
- **LM の前の並び**: `NON_LM_RANKERS`（cost、left_context、kana_style、doc_cache、learning、profile、topic）にない最初の Ranker（LM）を呼ぶ直前の score を控える。Guard が働く構成では Guard を適用したあとの score。LM がなければ控えず、段は何もしない（LM なし・secure で LM が無いときは結果が変わらない）。
- **判定**: 候補の分割（`Segment`）の隣り合う 2 語が、どちらも辞書の語で、前が「サ変でない名詞」、後が「サ行変格・文語サ行変格の動詞、または 文語下二段-サ行 の助動詞」。ラティスの辺の補正（`noun_suru_extra`）と同じ品詞の分類（`suru_class_of`）を使い、`lattice::has_noun_suru_edge` に切り出した。新しい閾値や重みは足さない。候補の分割は語 ID・品詞 ID を持つので、判定に足りる情報が候補にそろっている。
- **戻し方**: LM の後の1位の score より 1 小さい値を、LM の前の1位に付ける（ADR 0020 と同じ）。ほかの候補の score は変えない。
- **B32（ADR 0020）との順序**: B40 の段を **B32 の前**に置く。理由: B32 は「最終的な1位が英字のとき、カタカナを繰り上げる」表示の規則で、1位が確定したあとに当てるもの。B40 が先に1位を確定し、残った1位に B32 を当てれば、B32 は B40 の結果を見て正しく働く。逆にすると、B32 が繰り上げた候補を B40 が戻して英字が1位に戻りうる。
- **assemble**: `stack/src/assemble.rs` が `CompositeRanker::keep_noun_suru(convert.noun_suru.is_enabled())` で、規則 S の有効・無効に合わせる（契約・proto は変えない）。

## 4. 測定（2026-10-16。LM あり: zenz-v3.2 small、締め切り 2000ms、時間切れ 0）

- **rare-homophones（LM あり）**: 基準（main = 2e9dbf5 のバイナリ）と比べると、1位が変わるのは上の 4 件だけ（げんきんする 現金する → 厳禁する、てんじょうする 天井する → 添乗する、じたくする 自宅する → 支度する、ずしする 寿司する → 図示する）。1位の正解 61 → **65** / 77。悪化 0。
- **snapshot（`eval/scripts/snapshot.sh --compare`、基準 `snapshot-main-2e9dbf5`、LM あり・AJIMEE あり）**: 差分 **0**（一致）。eval の全セット（LM なしの 18、LM ありの 7）、segments、学習のシナリオ、CLI golden が基準と一致。LM の時間切れ 0（すべて有効）。homophones-cost の warm p99 の警告 1 件（0.139 → 0.226 ms。この構成は Cost 単独で `CompositeRanker` を通らないので、この変更とは無関係。原因は確かめていない）。
- **探索（調査のシミュレーション）**: 「LM が規則 S の辺を含む1位に上げない」とすると、LM で直る 213 件のうち失うのは 0 件（1977 → 1981）。
- 単体テスト（`core/src/ranker/composite.rs`）: LM を模した Ranker が覆そうとしても戻る、規則 S と無関係な LM の1位の変更は戻さない、LM の前の1位にも辺があれば戻さない、LM がなければ何も変わらない。

## 5. 却下した案

- **LM の重みを下げる（alpha = 0.5）**: 防げるのは 14 件に対し、LM が直す入力を失うのが 52 件で、正味 −38。LM は文脈の読み取りで多くの正解を直しているので、全体の重みを下げるのは代償が大きい。
- **(B) Ranker が決めた1位への一律の上乗せ（保留）**: LM の前の1位に一律の加点を付ける案。規則 S 以外の LM の変更も抑えるので、効果の範囲が広く、副作用を測っていない。規則 S の1点で足りる間は採らない。同じ型の覆しが他の規則で見つかったら、改めて検討する。
- **規則 S の値を上げる（+3000 → 5000）**: ゲーム擦る、テニス擦る が出る（ADR 0016 §6.4）。LM の前の並びでは正しいので、LM の後ろで戻すほうが副作用が小さい。

## 6. 影響範囲とリスク

- **変わるもの**: `CompositeRanker`（段の追加と `keep_noun_suru`）、`core/src/lattice.rs`（`has_noun_suru_edge` の追加）、`stack/src/assemble.rs`（1行）。
- **LM の前の1位が誤りのとき**: 規則 S が守った1位が誤りで、LM が正しく直していた場合も戻す。規則 S の対象は サ変でない名詞＋する で、LM が直す例は測定した範囲（上の 4 件以外の eval の全セット、探索 213 件）で 0 件。サ変でない名詞＋する が正解の入力（ゲームする など）は、LM の前の1位もそれなので影響しない。
- **締め切りに間に合わない LM**: LM が効かなければ、LM の前と後で1位は同じで、段は何もしない。
- **学習との関係**: 学習は LM の前に適用されているので、ユーザーが 現金する を選んで学習していれば、LM の前の1位が 現金する になり、戻されない。
