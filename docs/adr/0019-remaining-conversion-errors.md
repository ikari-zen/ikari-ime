### 0.3 測っているうちに分かった、同じ型の誤り（B17 の外）
- **左文脈が数のときの助数詞**（§2 の群 2 の対象）: 十 + ふん → 墳、百 + えん → 園、二 + けん → 圏、三 + しゅう → 州、十 + びょう → 病、三 + だい → 大。算用数字の文脈（10 + ふん、100 + えん、3 + じ）も同じ。午後三 + じ はこの型の1件。
- **読みに算用数字を含む入力**（3じに → 3字に、10ぷん → 10墳、100えん → 100園、2かい → 2海、2026ねん → 2026ねん）: ローマ字の数字は読みに半角のまま入り（`input` の `kana("1") == "1"`）、辞書に読み "3" の項目がないので、1文字ずつの未知語のノード（品詞は未知語の既定 = 名詞,普通名詞,一般）になる。数詞の連接を受けないので、助数詞が選ばれない。**この ADR の B17 では扱わない**（§8-5。B35 として §14 で直した）。
- **同音の助数詞 回 / 階**: いっかい、さんかい（1位 三階）、すうかい（数階）、だいいっかい（第一階）。もういっかい と同じ原因（語のコスト 階 < 回）。
- ひきすうめい は、§2 の群 1 の規則で 引き数名 が消えると 引数姪 が1位になる（引数 → 姪 が 引数 → 名 より安い。別の原因）。

## 2. まとめて直す群の案

### 2.1 群 1: 規則 N「前の語 → 数詞 数」の辺を、覆う名詞があるときだけ重くする

- 定義: 辞書のノード P（品詞2 が 数詞 でないもの。品詞1 は問わない: 接頭辞 低、代名詞 かん、名詞 編、動詞 引き）→ 辞書のノード N（品詞 = 名詞,数詞 で、読みが **すう**）の辺に、P の開始位置から N の終了位置までをちょうど1語で覆う名詞（変換用のコスト ≤ 10000。ADR 0008 と同じ表 `cover_ends`）があるときだけ、+6000 を足す。
- 形は ADR 0008 §13（名詞 → 接尾辞）と同じ。違うのは辺の品詞の組だけ。覆う名詞の上限 10000 と値 6000 は既存の規則と同じにする。
- なぜ 数（すう）だけか: 前に数でない語が来て、しかもその読みを1語の名詞が覆う数詞は、〜数（変数、関数、定数、引数、係数、件数、回数 など）の形がほとんど。「数名」「数人」の 数 は、前が数（十数名）か文頭（数名）で、覆う名詞の表記も同じになる（生徒数名 = 生徒数 + 名、複数名 = 複数 + 名）。数詞の全体に広げた形（案 N2）も測ったが（§2.1.2）、得るものは同じで、計三人 の順位が下がった。

#### 2.1.1 測った値（snapshot。基準は同じ試作のバイナリで規則を止めたもの。main のバイナリの snapshot と差分 0 を確認済み）

| homophones（cost / topic / full）、ext dev・test、hiragana、context-compound、adverbs、verbs、compound-affix、new-words、rare-homophones、formal-noun-split | ― | 同じ | なし（ケースごとの列 1〜7 が一致） |

- 値: +2000 では 関数名 が届かず（かん数名 のまま）、+3000、+6000、+10000 は同じ結果（平坦）。
- 自然な入力（セットにない 51 件。LM なし）: 十数名、二十数名、数名、生徒数名、複数名、社員数名、数十人、十数年、数人、数年後、回数、件数、整数、点数、枚数、個数、係数、変数、関数、定数、少数、多数、半数、百数十人、因数、偶数、奇数、各一名、各二名、約三人、小数点、数学、多数決、一日、統一、唯一 などは、1位が変わらなかった。変わったのは へんすうめいをかえる（編数名を帰る → 変数名を帰る。改善。帰る は別の誤り）だけ。

#### 2.1.2 案 N2: 数詞の全体（読みを問わない）
同じ snapshot で katakana-suffix +3、ほかに順位だけの改善（compound-affix の 規格化 22 → 20 位、rare-homophones の 学部 4 → 3 位）。自然な入力では、けいさんにん（期待 計三人。今も 計算人 が1位）の 計三人 の順位が 4 → 24 位に下がった（計 + 三 を 計算 が覆う）。1位の悪化はないが、得るものが規則 N と同じで、効く範囲を見積もれない分だけ広い。**採らない**。

### 2.2 群 2: 左文脈の最後の語が数詞のときは、助数詞の名詞も増幅する（規則 C）

- 今の LeftContextRanker（ADR 0002 §22）は、名詞で始まる候補の連接を増幅しない（同音の名詞どうしを乱さないため）。数のあとでは、助数詞が 接尾辞（次、墳、園、圏、州、病）か 名詞,普通名詞,助数詞可能（時、分、円、件、週、秒、台）かで、最大 6000 の差が付く（phase3-suffix §2.3、ADR 0007 §0.2 と同じ非対称）。
- 案: 左文脈の最後のトークンの品詞が 名詞,数詞 で、候補（1語）の品詞に 助数詞 を含む（名詞,普通名詞,助数詞可能 と 接尾辞,名詞的,助数詞）なら、名詞でも増幅する。どちらの助数詞も上限の -6000 になり、経路のコストで決まる。
- ADR 0007 §9 の案 B-2（助数詞可能の名詞を、左文脈によらず増幅する）は、しゅうかん の 4 件（ext dev）が入れ替わって採らなかった。規則 C は、左文脈が数詞のときだけに絞る。

## 3. 1語ずつの手当てが要るもの（群 3）

### 3.1 規則で直す形（案 A: 副詞 → 動詞 の辺に覆う名詞の規則を広げる）は退けた
申し訳（もうしわけ）は もう（副詞）+ 仕分け（動詞）の範囲をちょうど覆う名詞なので、ADR 0008 の規則を 副詞 → 動詞 の辺に広げれば直る。試作して測った（+6000、上限 10000）。

| 形 | セットで直ったもの | セットでの悪化 | 自然な入力（40 件）での悪化 |
| --- | --- | --- | --- |
| 副詞 → 動詞 | adv-pred-12 申し訳ない、adv-kango-44 同士 | adv-pred-03 どうしたの → どう下の（どう + し を 同志・動詞 が覆う） | （測っていない） |
| 副詞 → 動詞・形容詞 | 同上 | 同上 | （測っていない） |
| 副詞 → 名詞でないすべて | 上に加えて 航行する、ext の 効果・硬貨 の順位 | どうしたの、こうかな → 高価な、どうかな → 道かな | （測っていない） |
| 副詞 → 動詞（動詞が 2 文字以上） | adv-pred-12 申し訳ない | なし | **そうかいてある → そうか居てある、こうかいてある → こうか居てある、こうかいた → こうか居た、そうかいた → そうか居た、そうかいてあった → そうか居てあった** |
| 副詞 → 名詞でないすべて（2 文字以上） | adv-pred-12、rh-suru-15 航行する | なし | 同上 |

最後の 2 つは、そう + 書い を 総会・爽快 が覆い、重くした経路が逃げ道の そうか + 居 に流れた（ADR 0011 §4.1 と同じ型）。並びの規則は、覆う名詞のある読み（そうかい、こうかい、どうし）で、副詞 + 動詞が正しい入力（そう書いてある）を崩す。申し訳 1語のために入れる形ではない。**採らない**。

## 10. ユーザーに聞くこと

1. **群 1（規則 N）を入れるか**
   - 背景: へんすうめい → 編数名、かんすうめい → かん数名、ていすうめい → 低数名。「数名」（何人か）の 数 は数詞で、数詞 → 名 の連接が -9025 と非常に安いため、変数 + 名 より 編 + 数名 が勝つ。B25（名詞 → 接尾辞）では 低 が接頭辞なので直らなかった。

2. **群 2（規則 C）を入れるか**

   - 選択肢: (a) 数詞の文脈のときだけ助数詞の名詞も増幅する: セットで +2（午後三 + じ が 2 つのセットにある）、自然な入力で 8 件直り、二 + じ が 次 → 時 に変わる（どちらも自然）。(b) 入れない。
   - **推奨: (a)**。数を確定してから助数詞を打つのは、こまめに確定する使い方で起きやすい。
   - 確認: 二 + じ、三 + とう、二 + かい のような、期待が文脈で決まるものを評価セットでどう扱うか（両方を正解にする案）。
3. **申し訳ない（群 3）の直し方**
   - 背景: もうしわけない／ありません／ございません／なかった が、もう仕分け… になる。辞書に 申し訳ない の1語の項目がなく、並びの規則（副詞 → 動詞）は そう書いてある → そうか居てある を崩す（§3.1）。

   - **推奨: (a)**。1語のために仕組みを作らない。同じ型の語が増えたら (b) を考える。登録はユーザーの手で行う（ユーザーデータは書き換えない約束のため、こちらでは行わない）。
4. **回 / 階（群 4）を別タスクにするか**
   - 背景: 数のあとの かい は、どれも 階 が1位（もういっかい、いっかい、さんかい、すうかい、だいいっかい）。語のコストが 階 < 回 で、chiVe の頻度は 回 の方がずっと高い（155 位 / 906 位）。学習 1 回で もういっかい は直るが、ほかの数の読みは2位まで。

5. **読みの算用数字（§0.3、§8-5）を新しいタスクとして積むか**

## 15. 読みの中の数字のあとの助数詞（規則 K。2026-10-22。#219）

### 15.1 原因（`2けん` などの経路の分解。LM なし、学習ゼロ）
- 助数詞可能の名詞（件・秒・階・杯・倍 など）は、数詞 → 助数詞 の連接が安い（約 -4300）代わりに、**語のコストが高い**（8000 前後）。同音の普通名詞（県 1822）や接尾辞（湖・病・圏）は語のコストが安く、連接が -2660〜+322 でも合計で勝つ。例: けん → 県 2144 / 圏 2226（+ ime_penalty 1232）/ 件 3934（コストと連接の合計。ime_penalty を除く）。
- 辞書の品詞づけは一貫しない: 件・秒・階・杯・倍・票 は `名詞,普通名詞,助数詞可能`、個・年生・刷・日 は `接尾辞,名詞的,助数詞`、冊・位 は `接尾辞,名詞的,一般`。
- 2かい の 2日位 は 日 + 位 の分割で、階・回 の問題とは別（日 が 接尾辞,助数詞 で連接が安い）。階 の側を軽くすれば勝つ。
- 3かげつ は、辞書の か月 に ime_penalty（1500）、カ月 に 6500 が付いていて 3か月 が出ない（3箇月 は 4位）。この規則の対象外。

### 15.2 規則 K（案: 数詞 → 助数詞の辺を軽くする。重くする案は採らない）
- `lattice.rs` の `numeral_counter_extra`。`prev` が**読みの中の数字の未知語**（`名詞,数詞`。§14 で品詞をつけたもの）、`next` が辞書の `名詞,普通名詞,助数詞可能` なら `-bonus`。設定は `lattice.numeral_counter.bonus`（`NumeralCounterRule`。0 で止まる。規則 V と同じく負の値を返し、前向きと後ろ向きが同じ関数なので A* のヒューリスティックは正確なまま）。
- **辞書の数詞（いちど の 一 など、かな読みから作ったもの）には当てない**: 最初に当てたら、もういちど → もう一℃、きゅうがた → 九方、ていすうめい → て居数名 など 12 件が 1位から落ちた（katakana、adverbs、compound-affix、ext-dev の jiki）。

## 19. 「第」+ 数詞のあとは、序数に使う助数詞を優先する（`ordinal_bonus`。2026-10-23。#240）

### 19.1 問題
`だい10かん` は 第10缶、`だい3かい` は 第3階（第3回は 3 位）、`だい2しょう` は 第2升、`だい5わ` は 第5羽 になっていた。文脈なしの `10かん` は、文脈で巻・缶が切り替わる（LM あり）ので、「第」付きだけが外れていた。

### 19.2 決定
- 読みで「だい」の直後に続く数（数字の並びの各桁、およびその直後の辞書の数詞）のノードに印を付け、そこから序数の助数詞への辺を `ordinal_bonus` だけ引く。辺の規則は前後 2 ノードしか見ないので、「第」の判定はラティスの構築時に位置で行う（`Node::ordinal_numeral`）。
- 序数の助数詞（ユーザー決定 2026-10-23）: 巻 回 章 節 話 条 項 号 位 番 期 次 部 課 版（`ORDINAL_COUNTER_SURFACES`）。**階（個数にも使う）と 年生（第3年生と言わない）は入れない。** 番・版 は番号の助数詞の規則（#202）と重なるが、第 + 数詞 のあとでは序数として扱う。
- 既定 `ordinal_bonus` = 8000（`--ranker-config` の `lattice.numeral_counter.ordinal_bonus`。0 でこの規則だけ止まる）。

### 19.3 掃引（辞書は ABR 入り。評価セットは eval/sets/ の全 24 セット）
- LM なし: 0 / 2000 / 3500 / 5000 / 6000 / 7000 / 8000 / 10000 / 12000。全値で、ほかのセットの 1 位の悪化は 0 件。
  - 2000: 巻・回・条・期 が 1 位。
  - 3500: 第2章 も 1 位。
  - 7000 まで: 第5話 は直らず（第5羽 が 3 位に残る）。8000 以上で 1 位。
- LM あり（`--lm-budget-ms 2000 --lm-deadline-ms 2000`）: 0 と 8000。1 位の悪化は 0 件。counters は 101 → 102（第5話）。
- 8000 を選んだ理由: 1 位が悪化せず、追加した 7 件の「直る」がすべて 1 位になる最小の値（話 は助数詞可能の名詞でないため、羽 の bonus 3500 に勝つ分が要る）。
- 評価の追加: counters.tsv に 11 行（直る 7、守る 4: 第10番、第10版、10かん、3かい）。期待はユーザー確認待ち（#185）。

### 19.4 残るもの・限界
- 「だい」が 台・代 の読みでも印が付くため、台3回 のような候補も上がる（第 が 1 位のまま。順は変わらない）。
- 漢字の「第」を直接打った入力（読みに「だい」がない）には効かない。
- 第3ねんせい は、期待を決めずに今のまま（第3年生）。
