# ADR 0017: 形式名詞の漢字の加点を、助詞が続く位置のほかは同じ形の候補の中に限る（ものごと → 物後と）

- 状態: 承認（2026-10-15 ユーザー決定。§11）
- 日付: 2026-10-15
- 対象: core の KanaStyleRanker（`core/src/ranker/kana_style.rs`）の規則 `formal_noun` のうち、実質名詞の漢字への加点（`formal_kanji_bonus`、既定 3500）だけ。

## 0. 現状の把握

### 0.1 現象と、測った原因
文脈なし、空の学習、LM なし、`--ranker full`。「スコア」は Ranker のあとの値、「経路」は辞書と連接のコスト（`ikari --format tsv` の3列目と4列目）。

| 入力 | 1位（スコア / 経路） | 1語の候補（スコア = 経路） | 差の出どころ |
| --- | --- | --- | --- |
| ものごと | 物後と（7162 / 10662）。物 + 後（接尾辞）+ と | ものごと 8920、物事 9227 | 物 に -3500 |
| ものほし | 物星（9466 / 12966） | 物干し 9702 | 物 に -3500 |
| ものごし | 物御市（9921 / 13421）。物 + 御（接頭辞）+ 市 | 物腰 10987 | 物 に -3500 |
| ものみ | 物味（10941 / 14441）。物 + 味（接尾辞） | 物見 11349 | 物 に -3500 |
| くせもの | 癖物（8280 / 14280） | 曲者 10660 | 癖 と 物 に 3500 ずつ（上限 `max_total` 6000） |
| ものいい | 物善い（10783 / 14283）。物 + 善い（形容詞,非自立可能） | 物言い 10906 | 物 に -3500 |
| もののけ | 物の毛（10414 / 13914） | 物の怪 10479 | 物 に -3500 |
| のみもの | のみ物（8062 / 11562）。のみ（副助詞）+ 物 | 飲み物 8756 | 物 に -3500 |

- どれも、**経路のコストでは1語の候補が勝っている**。誤りの候補だけ、スコアが経路より 3500（くせもの は 6000）小さい。
- `--ranker-config` で `kana_style.formal_kanji_bonus=0` にすると、ものごと の1位は ものごと（2位 物事）になり、`--ranker cost` の1位と同じになる。
- 3500 は `formal_kanji_bonus`。表の `formal_noun` のうち漢字を持つ5語（もの=物、とき=時、ところ=所、わけ=訳、くせ=癖）の**漢字の表記**が、直前が連体修飾でない位置（文頭、助詞のあと、名詞のあとなど。`Before::Nothing | Before::Other`）に現れると、語ごとに加点する（ADR 0002 §22）。
- 加点の条件は**読みと表記だけ**で、品詞も、次の語も見ない。物 が接頭辞（物足りない の 物）でも、接尾辞や名詞が続いても加点する。だから、読みの頭の もの・とき・わけ・くせ を 物・時・訳・癖 で切り出した候補が、加点のぶんだけ上がる。
- ADR 0010 §0.2 の本動詞の漢字の加点と**同じ型の漏れ**（表記の選択のための加点が、区切りの違う候補との比較に効く）。

### 0.2 ADR 0010 の形（同じ形の組の中だけ）を広げるだけでは直らない
ADR 0010 の規則（各語の読みと品詞1 が同じ候補の組の中だけで加点し、組の最良のスコアは加点の前に戻す）に、形式名詞の漢字の加点も入れると（ADR 0010 §7 の案 H。頭打ちを分けたものを、この ADR では案 H2 と呼ぶ。§6）、ものごと は直るが、hiragana の hira-kan-15 が落ちる。

| 入力 | 今 | 組の中だけ（H2） | 理由 |
| --- | --- | --- | --- |
| ものがたりない | 物が足りない（8072 / 11572） | 物語ない（9146） | 物が足りない の組の最良は ものが足りない（10814）。経路のコストでは 物語ない（9146）が 1668 安い |

- `formal_kanji_bonus=0` でも 物語ない が1位になる。つまり hira-kan-15 は、**加点が区切りをまたいで効くことに頼って**正しくなっている。物 + が + 足りない のように、実質名詞が助詞を伴って1つの文節になる位置では、加点が区切りの選択に効くのは規則の意図どおり（ADR 0002 §22。kana_style.tsv の注釈「文頭、「が」「を」の直後など」）。
- ADR 0010 §5.1 の案 H は hiragana 135（当時）だった。今の main では 136 → 134（hira-kan-15 と hira-kan-12 時が経つ）。hira-kan-12 は、本動詞の漢字（経つ）と形式名詞の漢字（時）を同じ枠に入れて `max_total`（6000）で頭打ちにしたための副作用で、上限を別々に取れば戻る（H2 は 135。hira-kan-15 だけ落ちる）。

### 0.3 漏れの広がり（評価セットにない入力）
今の評価セットには、この型の入力がほとんどない（ものがたりない、ときがたつ、ものをおく、ときをわすれる の4件は、どれも「実質名詞 + 助詞」で守る側）。そこで、試作で2つの探り用の入力を作った（scratchpad。コミットしていない。期待はおおよそで、ユーザーの確認を経ていない）。

- **語句（71 件）**: 区切りの漏れが疑われる語（ものごと、ものほし、ときどき、くせげ など 35 件）と、守りたい「実質名詞 + 助詞」などの句（ものがたりない、ときがながれる、わけをきく、くせになる、ものはためし、かいものにいく など 36 件）。
- **辞書（265 件）**: SudachiDict の small_lex と core_lex から、読みが もの／とき／ところ／わけ／くせ で始まり、それより長く、漢字を含む名詞・動詞・形容詞・副詞・形状詞の読み（固有名詞は除く）。期待は「同じ読みでいちばん安い項目の表記」（例: ときはなつ → 解き放つ、ものいい → 物言い）。まれな語が多い。

今のコードで、辞書の 265 件のうち 1位が期待と一致するのは 89 件。外れの多くは 時 + 動詞（時話す、時聞かせる、時伏せる）、訳 + 名詞・動詞（訳前、訳会う）、物 + 名詞・接尾辞（物星、物味）のような、加点つきの 物・時・訳・癖 で読みの頭を切り出した候補だった。

## 1. 決定の要約

| 項目 | 内容 |
| --- | --- |
| 規則 | 形式名詞の漢字の加点（`formal_kanji_bonus`）は、**次の語が助詞（「の」を除く）のときだけ今のまま**（区切りをまたいで効く）。それ以外（次が名詞、接尾辞、接頭辞、動詞、形容詞、助動詞、「の」、または候補の末尾）では、ADR 0010 と同じ**同じ形の組の中だけ**で効かせ、組の最良のスコアは加点の前に戻す |
| 助詞の判定 | 次の語の品詞1 が「助詞」で、表記が「の」でない（が、を、は、に、も、と、で、へ、から、まで、のみ、ばかり など） |
| 組 | ADR 0010 §2.1 と同じ（辞書由来の候補で、各語の読みと品詞1 の列が同じもの）。本動詞の漢字の加点と同じ組の処理に、別々に `max_total` で頭打ちにした値の和として入れる |
| 変えないもの | `formal_bonus`（連体修飾のあとのひらがな）、`phrase`、補助動詞の規則、表、値（3500、`max_total` 6000）、ほかの Ranker、ラティス |
| 新しい値・設定キー | 持たない |

## 2. 規則

### 2.1 定義
KanaStyleRanker の `segment_bonus` で、形式名詞の漢字の加点が付く語（今と同じ条件: 表の `formal_noun` の漢字の表記で、直前が `Before::Nothing | Before::Other`）について、次の語 `next` を見る。

| `next` | 加点の扱い |
| --- | --- |
| 品詞1 が「助詞」で、表記が「の」でない | 今と同じ。`general` に足す（区切りをまたいで効く） |
| それ以外（`None` を含む） | `shape_local` に足す（同じ形の組の中だけ） |

- `shape_local` は、今の `main_verb_kanji`（ADR 0010 の `a`）を広げたもの。本動詞の漢字の加点と、上の形式名詞の漢字の加点を、それぞれ `max_total` で頭打ちにしてから足す（`min(本動詞, max_total) + min(形式名詞, max_total)`）。同じ枠で頭打ちにすると hira-kan-12 が落ちる（§0.2）。
- 組の処理は ADR 0010 §2.1 のまま（`apply_main_verb_kanji` を `shape_local` に使う）。組の中の順と差は「加点して比べる」と同じで、組の最良のスコアは加点の前の値。組が1件、または組の全員の `shape_local` が 0 なら何もしない。
  （試作は組の処理を本動詞と形式名詞で2回通した。組の中の順と最良のスコアは、和を1回通すのと同じになる。）

### 2.2 なぜこの形か
- **加点の2つの役目を分ける**: `formal_kanji_bonus` は、(1) 同じ語の表記（もの → 物）を選ぶことと、(2) 実質名詞が助詞を伴って文節になる区切り（物 + が + 足りない、時 + が + 経つ）を、ほかの区切り（物語ない など）より上げること、の2つに使われている。(2) は規則の意図（kana_style.tsv の注釈「文頭、「が」「を」の直後など」は実質名詞として漢字）で、hiragana の hira-kan-15 が頼っている。(1) を区切りに漏らさないのが ADR 0010 の考え。
  **「次が助詞」は、(2) が成り立つ位置**（その名詞で文節が終わる）を、候補の中の情報だけで見分ける条件になる。物後と（次が接尾辞）、物星（名詞）、物御市（接頭辞）、物善い（形容詞）、のみ物（末尾）は (2) に当たらず、(1) だけが残る。
- **「の」を除く**: 物の怪 と 物の毛、時の間 と 時のま のように、「の」は1語の熟語の中にも現れる。「の」を助詞に含める案（P2）は 物の怪 を直せない（§4.3）。ときのながれ（時の流れ）のような句は、同じ形の組の中で比べても今と同じ1位だった。
- **否定の条件（次が名詞・接尾辞・接頭辞なら加点しない）にしない**: 試作の N3。加点を消すので、物 と もの の表記の選択まで消える（ものいみ → もの意味、ものみな → もの皆）。動詞や形容詞が続く漏れ（時聞かせる、物善い）も直らない（§4.3）。
- **肯定の条件で加点を消す（次が助詞・助動詞・末尾のときだけ加点）にしない**: 試作の N1。物足りない（物 は接頭辞 + 足り）が、加点の残る 物たりない（物 + たり（助動詞）+ ない）に負け、ところかわれば の 所変われば（名詞 + 動詞。助詞の省略）が 4 位から 14 位に落ちた。
- **Ranker の中で閉じる**: ADR 0010 §2.2 と同じ。`--ranker cost` ではもともと1語の候補が勝っている（§0.1）ので、原因の加点がある場所で直す。

## 3. 置き場所

- `core/src/ranker/kana_style.rs` の `KanaStyleRanker` だけ。`Bonus::main_verb_kanji` を `shape_local`（同じ形の組の中だけで使う加点）に改め、`segment_bonus` の形式名詞の漢字の分岐で、`next` に応じて `general` か `shape_local` に足す。`rank` の頭打ちを、本動詞と形式名詞で別々に取る（§2.1）。
- `next` は `segment_bonus` がすでに受け取っている（補助動詞の判定で使っている）。品詞1 は `grammar.pos_name(next.pos_id)` で引く。新しい表や値は要らない。
- `Ranker` トレイト、`Candidate`、CompositeRanker、Guard は変えない。KanaStyleRanker は Guard の追跡の対象外（ADR 0010 §3）。
- モジュールの説明（本動詞の漢字への加点は同じ形のまとまりの中だけ）に、形式名詞の漢字の加点の条件を足す。

### 4.3 探り用の入力（§0.3。LM なし）
1位の変化を数えた。「期待へ」は1位が期待に変わったもの、「期待から」は1位が期待から外れたもの。

| 案 | 語句 71 件: 1位の変化 / 期待へ / 期待から | 辞書 265 件: 1位の変化 / 期待へ / 期待から | 辞書 265 件の1位 |
| --- | --- | --- | ---: |
| 基準 | ― | ― | 89 |
| H2（同じ形の組の中だけ） | 9 / 7 / **1**（物語ない） | 61 / 42 / 2 | 129 |
| **P（次が助詞なら今のまま、ほかは組の中だけ）** | 8 / 7 / **0** | 55 / 35 / 2 | 122 |
| P2（P で「の」も助詞に含める） | 7 / 6 / 0 | 54 / 34 / 2 | 121 |
| N3（次が名詞・接尾辞・接頭辞なら加点しない） | 5 / 4 / 0 | 49 / 12 / 2 | 99 |
| N1（次が助詞・助動詞・末尾のときだけ加点する） | 7 / 5 / **1**（物足りない → 物たりない） | ― | 117 |

- 語句の P の「期待へ」7件: 物干し、物腰、物の怪、曲者、物言い、物見、飲み物。残る1件の変化は ものごと（物後と → ものごと。期待は 物事。§5-1）。
- 辞書の P の「期待から」2件は、期待の付け方の問題で、悪化ではない: ものもうで（物もうで → 物詣で）、わけあり（訳アリ → 訳有り）。同じ語の表記の違い。N3 の2件は ものみな（物皆 → もの皆）と わけあり。
- P で直らないもの（H2 なら直る）: ときはなつ（時は夏。解き放つ）、ものがしら（物が知ら。物頭）、ときがみ（時が身）。どれも 時・物 のあとが助詞として読める。時は夏 は文としても自然。
- N3 は加点を消すので、組の中の 物 と もの の選択も消える（ものいみ → もの意味、わけまえ → わけ前）。
- 辞書の 265 件はまれな語が多く、期待の表記も確かめていない。案どうしの相対の比較にだけ使う。

### 4.4 速さ
- 試作は、語ごとに環境変数を読み、文字列を作る、本実装より重い作り。それでも snapshot の warm p99 は P で「悪化なし」（基準の 1.1 倍以下か、差 0.05ms 以下）。
- 本実装は、形式名詞の漢字が付く語（候補の中に数語）で `next` の品詞1 を引くだけ。組の処理は ADR 0010 の既存の処理を使う。`scripts/check.sh --real --perf` で測り直す。

## 5. 失敗のしかた（既知の限界）

1. **ものごと は 物事 でなく ものごと になる**: 区切りの漏れは直るが、1語の ものごと（8920）と 物事（9227）は経路のコストで ものごと が安い（Sudachi のひらがなの項目）。公用文では 物事 と書くのが普通。同じ熟語のひらがなの項目と漢字の項目の選択は、形式名詞の規則（1語の もの、とき が対象）の外。直すなら別のタスク（§9-2）。
2. **次が助詞として読めると、今のまま区切りをまたぐ**: ときはなつ → 時は夏、ものがしら → 物が知ら、ときがみ → 時が身。物が足りない を守るための条件の裏返し。LM が間に合えば並べ替える。
3. **ひらがなへの加点（`formal_bonus`）にも同じ型の漏れがある**が、この ADR では変えない: 大きな + ものおき → もの置き（もの に 4000。経路 9913 → スコア 5913）。1語の 物置（8997）は5位。ひらがなの側は、困った + とき（と気 に勝つ。user-feedback.md §1.4）のように、末尾や助動詞が続く位置でも区切りをまたいで効くのが意図なので、P と同じ条件は使えない。別のタスクにするか（§9-3）。
   - **直した（B31、Issue #145）**: ひらがなの加点は、次の語が名詞・動詞・形容詞・接頭辞のときは付けない（助詞、助動詞、末尾はこれまでどおり）。大きな + ものおき は 物置 が1位。全評価セットで1位の悪化なし（fns-leak-20 の1件だけ 5位 → 1位）。
4. **接頭辞の 物 にも、組の中では加点が残る**: 物足りない の 物 は Sudachi では接頭辞だが、読みと表記が表に合うので加点の対象。次が動詞（足り）なので組の中だけになり、同じ形の もの足りない に 物 が勝つ（今と同じ1位）。品詞で 名詞 に限る条件は足さない（足すと、名詞の 物 + たり（助動詞）+ ない の 物たりない だけに、区切りをまたぐ加点が残る）。
5. **辞書の探り用の入力は確定した評価セットではない**: まれな語が多く、期待はおおよそ。回帰を見張るには、ユーザーが期待を確かめた小さなセットが要る（§9-4）。

## 7. 結果

- 得るもの: 形式名詞の漢字の加点が、熟語の読みの頭を 物・時・訳・癖 で切り出す誤り（物後と、物星、癖物、物善い、時聞かせる など）に漏れなくなる。物が足りない、時が経つ、物を置く、時を忘れる のような「実質名詞 + 助詞」は今と同じ。
- 失うもの: 形式名詞の漢字の加点が、次の語によって「候補ごとの足し算」と「同じ形の組の中」の2通りになる。`--format tsv` のスコアを手で分解するときは、次の語と組のずらしも数える。
- 波及:
  - ADR 0010 §6-5 に、この ADR への参照の注記を足す（本文は書き換えない）。
  - ADR 0010 の `main_verb_kanji` は `shape_local` に名前を変える（「表記の選択だけに使う加点」に意味を広げる）。
  - `formal_bonus`（ひらがな）の同じ型の漏れ（§5-3）は残る。

## 8. 実装の進め方

規模が小さい（`kana_style.rs` とそのテスト）ので、レーンを分けずに1つの code-editor で行う。

1. テストを先に足す（`kana_style.rs` の単体テスト。小さな辞書で）:
   - 物 + 接尾辞（物 + 後 + と）が、1語の候補（物事）を加点で追い越さない。
   - 物 + が + 足りない は、別の形の 物語 + ない を加点で追い越す（今と同じ）。
   - 物 + の + 毛 が 物の怪 を追い越さない（「の」は助詞に含めない）。
   - 同じ形の中では今と同じ差で 物 が もの に勝つ（候補の末尾の 物）。
   - 形式名詞と本動詞の加点を別々に頭打ちにする（時 + 経つ が同じ組に入るとき、7000 が 6000 に削られない）。
2. 実装（§2.1、§3）。モジュールの説明を直す。

4. ADR 0010 §6-5 に注記を足し、この ADR の状態と索引を更新する。

## 9. ユーザーに聞くこと

1. **規則の形（推奨: 案 P）**
   - 背景: 「ものごと」が「物後と」になる。形式名詞（もの、とき、ところ、わけ、くせ）を、文頭や助詞のあとでは実質名詞として漢字（物、時、所、訳、癖）にする加点 3500 が、物 + 後（接尾辞）+ と のように、熟語の読みの頭を切り出した候補まで押し上げている。B15（もう行っ海）と同じ型。
   - 難しさ: B15 と同じ直し方（同じ形の候補の中だけで効かせる）にすると、「ものがたりない」が「物語ない」に落ちる。物が足りない は、加点が区切りをまたいで効くことで正しくなっている。
   - 選択肢と影響（今の評価セットは、P、N3 とも1位の変化なし。違いは探り用の入力）:
     - **P（推奨）**: 次の語が助詞（が、を、は、に、も など。「の」は除く）なら今のまま、それ以外は同じ形の候補の中だけ。物後と、物星、癖物、物善い、物の毛、のみ物、時聞かせる が直り、物が足りない、時が経つ は今のまま。時は夏（ときはなつ）、物が知ら（ものがしら）は残る。
     - N3: 次が名詞・接尾辞・接頭辞なら加点しない。単純だが、物善い、物の毛、のみ物、時聞かせる は直らず、もの意味 のように 物 が ひらがなに戻るものが出る。
     - H2: 常に同じ形の候補の中だけ（B15 と同じ。規則がいちばん単純）。LM なしで直る数は最多だが、LM が間に合わないとき 物が足りない が 物語ない に落ちる（LM が間に合うと、今でも 物語ない が1位。LM ありでは H2 と P の差はない。§4.2）。
   - 推奨の理由: 加点の本来の役目（実質名詞が助詞を伴って文節になる位置での漢字）を残し、表記の加点が熟語の区切りを壊す部分だけを止められる。測った範囲で1位の悪化がない。
2. **ものごと の表記（§5-1）**: P のあと、ものごと の1位は ものごと（ひらがな。2位 物事）。辞書のひらがなの項目が安いため。公用文では 物事。
   - 選択肢: (a) この ADR の範囲外とし、学習（一度 物事 を選べば上がる）に任せる。(b) 同じ熟語のひらがなの項目と漢字の項目の選び方を、別のタスクとして測る。
   - **推奨: (a)**。B24 は区切りの漏れを直すタスクで、ものごと と 物事 は同じ語の表記の選択。(b) は実機で困る例が出てからでよい。
3. **ひらがなの側の同じ漏れ（§5-3）**: 「大きな」のあとの ものおき が もの置き になる（もの に 4000。物置 は5位）。ひらがなの加点は 困った + とき（と気 に勝つ）のように末尾でも区切りをまたぐのが意図なので、P と同じ条件は使えない。
   - 選択肢: (a) 別のタスクとして docs/tasks.md の B に積む。(b) 実機で困るまで積まない。
   - **推奨: (a)**。同じ型の漏れなので記録しておき、条件は別に測って決める。
4. **評価セットを足すか（§5-5）**: 今のセットにはこの型の入力がない。探り用の語句から、よく使う語（ものごと、ものほし、ものごし、ものいい、もののけ、のみもの、くせもの、ものおき、ときどき など）と守る側の句（ものがたりない、わけをきく、くせになる、ものはためし、ときのながれ など）を 30〜40 件選んで `eval/sets/` に下書きとして足し、期待をユーザーが確かめる（adverb-verbs と同じ扱い）。
   - **推奨: 足す**（下書きは本実装と同じブランチで作り、期待の確認は docs/tasks.md の A2 に積む）。足さない場合、P の効果と回帰は snapshot に現れない。
