### 0.2 最下位 を崩さずに直せる幅（最下位 にだけ足したとき、何点で入れ替わるか）

| 入力 | 1位 | 2位との差（最下位 に足す値がこれを超えると入れ替わる） |

| さいかい | 最下位（誤り） | 492 |

### 0.3 広さ（辞書から機械的に探した）
- `frequent_compound` の守りなしの層の語で、同じ読みに chiVe でより上位の「漢字を含む名詞」があるものは、Full で **28 語**（つくも 九十九／白、しょうがくせい 奨学生／小学生、さいかい 最下位／再開、ひとごと 他人事／人事、かいごしょく 介護食／介護職、しかい 歯科医／司会、しょうかき 消火器／消化器、せんきょく 選挙区／選曲 など）。
- そのうち、同じ読みに **1〜2 文字の名詞で 3 倍以上よく使うもの**がある語（ADR 0016 §6.5 の案 C の条件）は、**最下位 と 他人事 の 2 語だけ**。この形の規則は、実質的に 2 語の例外表になる。
- 28 語の読みだけを変換すると、複合語が1位の読みは 15 件。正しいもの（九十九、他人事、野薔薇、従兄弟、消火器 など）か、どちらでもよいもの（介護食／介護職、内科医／内海、更新料／香辛料）が多く、明らかな誤りは さいかい → 最下位、しかい → 歯科医、かがくてき → 化学的 くらい。

### 0.4 実機の「さいかいする → 最下位する が1位」（B26 の報告）
- 学習では再現しない: さいかい で 最下位 を 4 回確定しても、さいかいする は 1 再会する … 5 最下位する のまま（学習は読みごとで、さいかい の学習は さいかいする に効かない）。
- **文書内キャッシュで再現した**: 規則 S を止めた設定（`lattice.noun_suru.penalty=0`。B26 より前のエンジンと同じ）で、文脈「チームは最下位だった。来週から練習を」＋ さいかいする は **1 最下位する 5375**、2 再会する 6874。今の main（規則 S あり）では 3 位（8375）。
- ユーザーの手元は B26 のインストール前のエンジンだった（docs/tasks.md B26: インストールが残る）。同じ文書に 最下位 があったかは確かめていない（§9-3）。

## 2. 問題の定義
- 解きたいこと: 文脈なしの さいかい で、まれな 最下位 が、よく使う 再開・再会 より上に出る。
- 原因: `frequent_compound`（-8000）は「Sudachi が複合語の項目を高くしているので、分割に負ける」のを補う加点だが、分割だけでなく、同じ読みの1語の名詞にも勝たせてしまう。最下位 は 4 万位より上なので、同じ読みの名詞との比べ合い（ADR 0011 の守り）が当たらない。
- 制約: 最下位 は正しく使う語で、`frequent_compound` が守っている側でもある（加点がなければ、最下位 は 15136 で 再会 に約 6900 負け、文脈「リーグで」でも戻らない）。基本原則「学習は支援であって決定ではない」「選択肢を制限しない」。こまめに確定するのがコンセプト（短い読みの入力が多い）。

## 4. 提案する案: D（直さない）

### 4.1 なぜか
1. **文脈なしでは手がかりがない**（§0.2）。さいかい を 再会 にする値は、さいかいになる・さいかいだった・最下位に転落 も 再会 にする。試作のどの案も、さいかい 1 件を直す代わりに、読みの中で 最下位 が正しい文を崩した（§5.3）。
2. **規則が実質 2 語の例外表になる**（§0.3）。案 C・S の条件に当たるのは Full 全体で 最下位 と 他人事 だけ。広げると（C'、K、R）、介護食、消火器、選挙区、お雛様 のような正しい複合語を崩す（§5.2）。
3. **直しても、ユーザーの意図に届かないことが多い**。どの案でも さいかい の1位は 再会 になるが、ユーザーの報告の流れ（作業を さいかい）は 再開 で、どちらが要るかは人による（rh-user-08 は 再開 と 再会 の両方を許している）。再開 が欲しい人は、直したあとも学習が要る（案 S で1回、直さなければ2回。§5.5）。
4. **学習と文脈で直る形をしている**。2 回 再開 を選べば、文脈なしの さいかい は 再開 が1位になり、左の文脈がある入力（リーグで、順位は、チームは）は 最下位 のまま（§5.5）。LM（締め切り 2000ms）では、文の 18 件が 17 / 18（§5.4）。

### 4.2 失うもの
- 文脈なしの さいかい は、学習するまで 最下位 が1位のまま（rh-user-08 は失敗のまま）。初めの2回は Space をもう1〜2回押す。
- 既定の締め切り（読み 1 文字 6ms）では LM は間に合わず、文の中の 最下位を予定している、最下位の目処 のような誤りも残る（どの案でも直らない。再開 と 再会 の順の問題で、ADR 0016 §4.3）。

## 6. 退けた案

### 6.1 案 C・C'（加点を外す）
- 最下位 は加点がないと 15136 で、左の文脈（リーグで、約 2170）でも戻らない。rh-neg-01（リーグで＋さいかい → 最下位）が崩れる（ADR 0016 §6.5 と同じ。Full でも同じ）。C' は 介護食、競技会、後援会、奨学生、不要品 にも当たる。**採らない**。

### 6.2 案 K・K'（加点の上限を、よりよく使う名詞のコストにする）
- 「分割に勝つための加点が、よりよく使う1語の名詞まで追い越さないようにする」という考え方は筋がよく、AJIMEE で1件（瀬戸内海）上がった。しかし、同じ読みの名詞が どちらも複合語のとき（介護食／介護職、消火器／消化器、選挙区／選曲）にも効き、正しい複合語を崩した（§5.2）。K' は 他人事 に +5740 で、ひとごと が LM なしで 人ごと になる。最下位 が正しい文も崩れる（§5.3）。**採らない**。

### 6.3 案 R（よりよく使う名詞があれば加点を弱める）
- 2000 では 高齢者向けの＋かいごしょく → 介護職。3000 では リーグで＋さいかい も崩れる（§0.2 の 2664 を超える）。**採らない**。

### 6.4 案 S（1〜2 文字の、よりよく使う名詞があれば加点を弱める）
- 当たるのは 最下位 と 他人事 の 2 語だけで、規則の形をした例外表。値は §0.2 の幅（492〜756、1050）の間を狙うことになり、1000 は rh-neg-03（test の分け）の 1050 の手前を狙った値になる（ADR 0016 §6.3 と同じく、test のケースで値を選ぶことになる）。どの値でも 最下位 が正しい文が崩れる（§5.3）。LM ありでも 最下位を脱出 と ひとごと の 2 件が崩れる（§5.4）。**採らない**。

### 6.5 ほかに考えたが試作しなかった案
- **読みの後ろの語（に、だ、転落）で 最下位 を加点する辺の規則**: 「名詞,一般 → に」の連接はすでに 最下位 に有利で、さいかいになる と 再開になる（来週から再開になる）はどちらも自然。根拠になる並びがない。
- **Ranker で、候補に1語の同音語があれば複合語を下げる**: 文脈の加点（Topic）と同じ段階で効くので、左の文脈のない入力では §5.3 と同じ崩れ方をする。ADR 0011 §8 案 D と同じく、N-best の順とも食い違う。
- **再開 と 再会 の順を直す**（再開 は chiVe で 2.6 倍上だが、Sudachi のコストが 2121 高い）: B29 の範囲外。ADR 0016 §4.3 で規則にしないと決めている。

## 7. リスク
1. **さいかい は直らない**。初めの2回の手間はユーザーに残る（§4.2）。同じ型の誤り（しかい → 歯科医、かがくてき → 化学的）も同じ扱いになる（§0.3）。

3. **実機の さいかいする は、文書内キャッシュの仕組みで再現しただけ**で、ユーザーの文書に 最下位 があったかは分からない（§0.4）。規則 S の入ったエンジンをインストールしたあとに出たら、候補とコストの内訳（ログ）を取る。
4. **辞書の版を変えると §0.3 の数は動く**（chiVe の順位で決まる）。案 D はコードを変えないので、版の変更で新しい崩れは出ない。

## 9. ユーザーに聞くこと

### 9-1. さいかい（文脈なし）→ 最下位 を、辞書の規則で直すか
- 背景: 最下位 には「辞書に1語で入っている熟語を分割に負けさせない」加点（-8000。ADR 0011。けいたいそかいせき → 形態素解析 のときに広げたもの）が付いていて、よく使う 再開・再会 より上に出ている。この加点は 最下位 が正しい入力（リーグで＋さいかい、最下位に転落）も支えている。
- 具体例（LM なし）:

  | 入力 | 今（案 D） | 案 S（2000） |
  | --- | --- | --- |
  | さいかい | 最下位 | 再会 |
  | さいかいになる | 最下位になる | 再会になる |
  | さいかいにてんらく | 最下位に転落 | 再会に転落 |
  | せいせきはさいかいだった | 成績は最下位だった | 成績は再会だった |
  | リーグで＋さいかい | 最下位 | 最下位 |
  | 作業を＋さいかい | 再会 | 再会（どちらも 再開 にならない） |

- 選択肢と影響:
  - **D: 直さない**（推奨）。文の 18 件で LM なし 12、LM あり 17。さいかい は 再開 を2回選べば1位になる。辞書もコードも変えない。
  - S（2000）: さいかい は 再会 になる。最下位 が正しい文 5 件が崩れる（LM なし 9、LM あり 15）。rare-homophones は 45 → 44（rh-neg-02・03 が崩れ、rh-user-08 が直る）。辞書の作り直しが要る。
  - K'（加点の上限）: S と同じく 最下位 の文が崩れ、ひとごと が 人ごと、高齢者向けの 介護食 が 介護職 になる。
- **推奨: D**。文脈なしでは さいかい と さいかいになる を分ける手がかりがなく、さいかい 1 件のために 最下位 が正しい文を崩すことになる。直しても 再開 が欲しい人には学習が要る。

### 9-2. 最下位 が正しい文を、評価セットの否定のケースとして足すか
- 背景: rare-homophones.tsv の 最下位 の否定は 3 件（リーグで＋さいかい、さいかいになる、さいかいだった）で、文の中の 最下位（転落、脱出、逆転、成績は）がない。今回の試作では、これがないと案 S が「悪化 2 件」に見え、文での崩れ（5 件）が見えなかった。
- 選択肢: (a) 5 件（さいかいからのぎゃくてん、さいかいにてんらく、さいかいのちーむ、さいかいをだっしゅつ、せいせきはさいかいだった）を否定として足す、(b) 足さない。
- **推奨: (a)**。期待は Claude の下書きなので、REVIEW.md で確認してもらう（A2 に足す）。

### 9-3. 実機の さいかいする → 最下位する
- 背景: CLI では、同じ文書に 最下位 があると、B26 より前のエンジンで 最下位する が1位になることを確かめた（§0.4）。今の main（規則 S あり）では 3 位。ユーザーの手元は B26 のインストール前。
- 聞くこと: そのときの文書に 最下位 があったか（覚えていれば）。B26 をインストールしたあとに再び出たら知らせてほしい（ログを取る）。

### 9-4. rh-user-08（さいかい → 再開 か 再会）の扱い
- 選択肢: (a) 期待はそのままにして、既知の誤りとして note に書く、(b) セットから外す。
- **推奨: (a)**。学習や LM の変更で直ったときに分かるように残す。
