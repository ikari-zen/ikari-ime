## 0. 現状の把握

### 0.1 現象と原因（測った値。レポート §1）
ユーザーの報告（2026-10-14）: けいたいそかいせき → **携帯素解析**（期待 形態素解析）。ユーザーの言葉は「こういう熟語では疑いの余地なんてないから一語としてとれないかな？辞書には言葉が入ってるのでは？」。

| 経路（文脈なし、LM なし） | 合計 |
| --- | ---: |
| 携帯 + 素（接尾辞）+ 解析（1位） | **20300** |
| 形態 + 素（接尾辞）+ 解析（5位） | 22970 |
| 形態素（1語）+ 解析 | 24400 |

- 携帯 と 形態 の差 2670 は、語のコスト 696、`lemma_rank` 737、BOS の連接 188、**名詞 → 接尾辞 素 の連接 1049**（サ変可能の 携帯 が -3669、一般の 形態 が -2620）。どれも Sudachi の解析用の値や頻度の差で、「素 が付いて熟語になるのはどちらか」を表していない。
- 辞書には 形態素（名詞,普通名詞,一般。コスト 12625）がある。しかし chiVe の順位が 83455 位なので `lemma_rank` が +3843 乗り、`frequent_compound`（4万位まで、-8000）は当たらない。1語の 形態素 は分割より 4100 高い。
- Ranker の寄与は 0（文脈なし）。LM（zenz）は締め切り 2000ms なら 形態素解析 を1位にするが、既定の締め切り（読み 9 文字で 54ms）では 携帯素解析 のまま。
- 形態素解析 は Core になく Full にある。Full でも chiVe にないので `lemma_rank` が +5227 乗り、24666 で負ける（Full の辞書で確かめた）。**Full にしても直らない。**

### 0.2 広さ（レポート §2）
辞書から機械的に探すと、同じ型（漢字3文字以上の1語の熟語 W が、同音の別の語 + 1文字の接尾辞・接頭辞の分割に負ける）が Core に **3457 語** ある（W の chiVe の順位: 4万〜10万 635、10万〜20万 654、20万より下 668、chiVe になし 1500）。全件を期待 W で流すと main の1位は 67 件だけ。
機械化 → 機会化、正当性 → 正答性、嗜好品 → 施行品、注射器 → 駐車器、地政学 → 知性学、懐疑的 → 会議的、非対称 → 非対象、抽象化 → 中傷化、恒常性 → 向上性、帰納法 → 機能法 など、専門用語と熟語が多い。

一方で、W にしてはいけない入力もある。同じ 3457 語のうち 139 件は、今の1位の方が chiVe で W より上位の表記だった（そうしき 葬式 ／ W 総指揮、しりょうかん 資料館 ／ W 史料館、うちゅうせん 宇宙船 ／ W 宇宙線、きせいちゅう 寄生虫 ／ W 帰省中）。**「辞書に1語で入っている」だけでは、疑いの余地がないとは言えない**。Sudachi には解析のための、まれな表記の熟語が多い。

### 0.3 既存の仕組みとの関係
- `frequent_compound`（ADR 0002 §22.2）は、まさにこの問題（Sudachi が複合語の項目のコストを高くしていて、分割に負ける）への加点で、条件は「名詞,普通名詞、表記 = lemma、漢字だけの3文字以上、chiVe の順位が4万位より上」。4万は 伊富魚（56691 位）が かいとう → か伊富魚 に化けるのを避けた上限（phase3-suffix §4）。値 -8000 は、-12000 から区切りの F1 が下がる崖の手前（phase3-compound）。
- ADR 0008 の「覆う名詞」は、ラティスで、副詞 → 名詞 の辺を、その範囲を1語で覆う名詞（コスト ≤ 10000）があるときだけ重くする。並び（副詞の直後の名詞）が悪く、語は正しい、という問題の形に合わせた仕組み。
- B17 の残り（効果測定、日本語版、変数名、範囲外）は、期待の熟語が Core にない。

## 2. 規則

### 2.1 定義
辞書の行 W に `frequent_compound` を当てるのは、次の (a)〜(c) をすべて満たし、かつ (d) か (e) のとき。

- (a) 品詞1 = 名詞、品詞2 = 普通名詞
- (b) 表記 = lemma
- (c) 表記が漢字だけで3文字以上
- (d) lemma の chiVe の順位 < 4万（今の規則）
- (e) 4万 ≤ lemma の chiVe の順位 < 10万 で、**同じ読みの行のうち、品詞1 = 名詞で表記に漢字を含むもの（固有名詞を含む）の lemma の chiVe の順位の最小が、W の順位以上**

### 2.2 なぜこの形か
- **「よく使う」の手がかりは chiVe の順位しかない**: ラティスや Ranker は Sudachi のコストしか見られない。熟語がよく使われるか、同音の別の表記の方が使われるかは、辞書を作るときに chiVe と照らすのがいちばん確か。今の `frequent_compound` も `lemma_rank` も同じ考え方。
- **上限を上げるだけでは崩れる（案 A0）**: 上限を10万にするだけだと、かいとう → か伊富魚（ext dev）、そうしき → 総指揮、しりょうかん → 史料館、きせいちゅう → 帰省中、うちゅうせん → 宇宙線、たきぎょう → 他企業 が崩れた。どれも、**同じ読みに、もっと使う漢字の名詞がある**（伊藤、葬式、資料館（分割）、寄生虫、宇宙船、滝行）。
- **同音の守りで、崩れたものがすべて止まる**: (e) の条件で、上の 6 件はすべて元に戻り、既存のセットの変化は 0 になった。守りは「辞書に入っている」から一歩進めて、「**その読みで、辞書の中でいちばん使われている漢字の表記である**」ことを求める。これが、ユーザーの言う「疑いの余地がない熟語」のいちばん近い言い換えになる。
- **固有名詞を守りに含める**: 既存の `kanji_peer_rank`（固有名詞と記号を除く。`katakana_analysis` が使う）をそのまま使うと、伊富魚（いとう）が守りを抜けて か伊富魚 が戻った。止めていたのは同じ読みの 伊藤（人名）だった。守りは「読みの衝突」を見るものなので、固有名詞も数える。
- **接辞の形で絞らない（案 A1、A2 との比較）**: 「頭 + 1文字の接辞に分けられる熟語だけ」に絞ると、当たる語は半分になるが、守りを入れた形どうしで比べると既存のセットの結果は同じで、大腸菌、磁性体、消火栓、急降下 のように頭が別の表記・別の切れ目になる語が漏れた（compound-affix 92 → 97）。条件が増える分だけ説明も難しくなる。
- **上限は10万**: 守りがあると、上限 10万、20万、なしで既存のセットは同じだった。20万から否定のセットに 1 件の変化（ちゅうかんし 中間市 → 中間子。どちらも自然）が出る。上限なしでは当たる語が 15691 になり、まれな語の加点が、セットにない入力でどう効くかを見積もれない。形態素（83455 位）を含み、変化が 0 の範囲の中で小さい 10万にする。
- **4万位以内には守りを当てない**: 当てると、歯医者、消火器、内科医、選挙区 など 24 語が外れ、しょうかき 消火器 → 消化器 が崩れた。4万位以内の語は頻度が十分高く、今の規則で問題が出ていない。
- **値は変えない**: -6000 では compound-affix 87（一部届かない）、-10000 では segments の完全一致 144 → 143、F1 0.994 → 0.989（phase3-compound の崖と同じ）。-8000 は平坦な範囲にある。

## 4. ADR 0008 の「覆う名詞」、B17、B15 との関係

### 4.1 共通の仕組みにしない
「1語で覆う語があるなら、それを分けた経路より優先する」という考え方は ADR 0008 と同じだが、**手がかりのある場所が違う**ので、仕組みは分ける。

- ADR 0008: 語は正しく（副詞 そう も、名詞 時期 も本物）、悪いのは並び。並びはラティスにしかないので、辺で扱う。覆う名詞のコストの上限（10000）は「ふつうに使う名詞か」の代わり。
- この ADR: 並びは正しく（名詞 + 接尾辞 は自然な形）、悪いのは「どの同音の語か」。決め手は熟語の頻度と、同じ読みのほかの表記の頻度で、これは辞書を作るときにしか見られない。
- 実際に ADR 0008 の仕組みを 名詞 → 接尾辞、接頭辞 → 名詞 の辺に広げる形（案 B）を測った。形態素（16468）を覆う名詞にする上限では、重くした経路が 際（名詞）、せい（ひらがな）、額 のような接辞でない逃げ道に流れ、segments の F1 が 0.994 → 0.983 に下がった（レポート §3）。
- ただし、この ADR で熟語のコストが下がると、ADR 0008 の「覆う名詞」（コスト ≤ 10000）になる語が増える（ADR 0008 §7-2 の予想どおり）。adverbs.tsv は LM なし・ありとも順位まで変わらなかった。

### 4.2 B17
B17 の 効果測定、日本語版、変数名・関数名・定数名、範囲外 は、期待の熟語が Core にない（効果測定 は Full にあるが chiVe にない）ので、この規則では直らない。
副産物として、案 B を上限 10000（今の ADR 0008 と同じ）で 名詞 → 接尾辞 の辺に広げると、ていすうめい 低数名 → 定数名、そうとう 層等 → 相当、かいとう（cost）会等 → 回答 が直り、どのセットにも悪化がなかった。B19 の熟語にはほとんど効かない（3457 語で +2）ので、この ADR には入れず、別のタスクにするかをユーザーに聞く（§10-6）。**→ B25 として入れた（ADR 0008 §13。2026-10-15）。低数名 は今の Full では分割が違って直らなかった。**

### 4.3 B15（ADR 0010）
ADR 0010 は KanaStyleRanker の加点の効き方（Ranker の段階）を変えるもので、この ADR は辞書の語のコストだけを変える。重なる対象はない。両方を入れたあとに snapshot を取り直す。

## 5. N-best、文節、学習との整合
- 候補を消さない。分割（携帯素）は N-best の後ろに下がるだけで選べる（基本原則「選択肢を制限しない」）。読みに対応しない文字は足さない（基本原則 1.1）。
- 区切り（ADR 0006）は1位の語の並びから作る。熟語が1語になると、その部分が1文節の中の1語になる（形態素＋解析）。segments セットの完全一致と F1 は変わらなかった。
- 学習（LearningRanker）は今どおり。ユーザーが 携帯素 を選べば、次から上がる（基本原則 1.2）。

## 7. 失敗のしかた（既知の限界）
1. **chiVe にない熟語は直らない**（Core で 1500 語。Full の 形態素解析、効果測定 も）。chiVe にない語まで広げると こう修正する → 高修正する（adverbs）、供花料 → 公家領 が崩れた。頻度の手がかりがない語は、学習かユーザー辞書で扱う。
2. **守りは chiVe の頻度の比べ合いで、意味は見ない**: 規格化 は、同じ読みの 企画課 の方が上位なので当たらない。逆に、同じ読みに漢字の名詞がない熟語は、熟語が多少まれでも当たる（中間子 のように、分割（中間市）が意図の入力もありうる）。
3. **分割が意図の入力**: 熟語が当たる読みで、ユーザーが 同音の語 + 接辞 を意図することはある（スパイクの否定のセット 139 件では崩れなかったが、網羅ではない）。候補には残るので、選び直せば学習で直る。
4. **辞書を作り直すと対象が動く**: 上限と守りは chiVe の順位で決まるので、Sudachi や chiVe の版を変えたら、compound-affix と否定のセットで取り直す。
5. **LM は並べ替えだけ**: 締め切りが長いときは LM も多くを直す（35 → 76）が、短い締め切り（Convert の直後、区切り直し）には間に合わない。規則で直る形は規則で直す（ADR 0008 §8 案 F と同じ）。

## 8. 検討した案

- **案 A0: `frequent_compound` の順位の上限を上げるだけ（10万）**: 伊富魚、総指揮、史料館、帰省中、宇宙線、他企業 が崩れた（§2.2）。**採らない**。
- **案 A1、A2: 接辞に分けられる熟語だけに絞る（A2 は守りつき）**: A2 は副作用がないが、大腸菌、磁性体、消火栓、急降下 が漏れる（compound-affix 92）。守りがあれば絞る必要がない。**採らない**。
- **案 A3（提案）: 守りつきで上限を 10万に広げる**: §1、§2。
- **案 B: ラティスの辺（ADR 0008 の拡張）**: 名詞 → 接尾辞、接頭辞 → 名詞 の辺を、覆う名詞があるときだけ重くする。熟語を覆う名詞にするには上限を 16500 以上にする必要があり、逃げ道（際、せい、額）に流れて F1 が下がる。頻度の手がかりがない。**採らない**（上限 10000 の形は §4.2 で別のタスクの候補にする）。
- **案 C: 接尾辞の1文字の分割にペナルティ（語ごと）**: 素、性、化、的 などの接尾辞は、正しい分割（構造＋化、文字列＋化）でも使う。並びも同音の区別も表せない（phase3-suffix §3 の `sahen_suffix` と同じ理由で崩れる）。**採らない**。
- **案 D: Ranker で、候補の中に1語の熟語と同じ読みの分割があれば加点**: 熟語の候補がプール（30 件）に入らないことがある（main で熟語の順位は 2〜42 位に散らばり、11 件は 30 位より下、7 件は 50 位以内にない）。N-best の順と食い違う（ADR 0008 §8 案 D と同じ理由）。**採らない**。
- **案 E: LM（zenz）に任せる**: 締め切りが長ければ多くを直すが、既定の締め切りでは 形態素解析 も直らない。23 件は LM でも直らない（嗜好品 → 施工品 など）。**採らない**（LM は今どおり並べ替えに使う）。
- **案 F: 辞書を Full にする**: 形態素解析 は Full にあるが chiVe にないので負ける。Full で直るわけではない（A3-3 の判断の材料にはならない）。

---

## 9. 結果（提案どおりに入れた場合）
- 得るもの: 専門用語と熟語（形態素、機械化、正当性、嗜好品、注射器、地政学 など）が、同音の語 + 接辞の分割に負けなくなる。変更は辞書のポリシーの条件1つで、コードの変更は `dict-builder` だけ。
- 失うもの: `frequent_compound` の条件が「順位の上限」1つから「上限 + 同音の守り」に増える。読みごとの値（同じ読みの名詞の最小の順位）を辞書を作るときに求める。
- 波及: 熟語のコストが下がるので、ADR 0008 の覆う名詞になる語が増える（測った範囲では変化なし）。ポリシーを変えたら、compound-affix と adverbs のセットも流す。

## 10. ユーザーの判断と決定

1. **規則の形**: 「`frequent_compound` を、4万〜10万位の熟語のうち、同じ読みの漢字を含む名詞（固有名詞を含む）の中でいちばん使われる語にも当てる」（§2.1）でよいか。「辞書に入っている」だけでは まれな表記（総指揮、史料館、宇宙線）が 葬式、資料館、宇宙船 に勝ってしまうので、「その読みでいちばん使われる表記」を条件にする。**推奨: この形で入れる**。
2. **上限**: 10万位（形態素 83455 位を含む）。守りがあれば 20万、上限なしでも既存のセットは同じだが、当たる語が 2 倍、3 倍になり、セットにない入力での効き方を見積もれない。**推奨: 10万**。
3. **4万位以内の今の対象には守りを当てない**（当てると 消火器 → 消化器 が崩れる）。**推奨: 当てない**。
4. **値**: -8000 のまま（-10000 は区切りの崖）。**推奨: 変えない**。
5. **評価セット** `eval/sets/compound-affix.tsv`（99 件）の正解の確認（docs/tasks.md A2-8。とくに否定 35 件の「よく使う方」）。**推奨: 確認してから本実装の基準にする**。
6. **副産物**: ADR 0008 の覆う名詞の規則を、名詞 → 接尾辞 の辺にも上限 10000 のまま広げると、低数名 → 定数名（B17）、層等 → 相当、会等 → 回答 が直り、悪化がなかった（§4.2）。これを別のタスクとして B に積むか。**推奨: 積む**（この ADR とは別に、自然な入力のセットで副作用を確かめてから）。
7. **辞書の版（A3-3）**: 形態素解析 は Full にあるが、Full にしてもこの問題は直らない（§0.1）。A3-3 の判断はこの件と切り離してよいか。**推奨: 切り離す**。

---

### 10.1 決定（2026-10-14）
1〜4、7 は推奨どおり。5 と 6 は次のとおり。

1. 規則の形: §2.1 のとおり。
2. 上限: 10万位。
3. 4万位以内の今の対象には、同音の比べ合い（守り）を当てない。
4. 値: -8000 のまま。
5. 評価セット `compound-affix.tsv` の正解の確認は、docs/tasks.md A2-8 に回す（確認を待たずに実装の基準にする）。
6. ADR 0008 の規則を 名詞 → 接尾辞 の辺に広げる案（§4.2）は、別タスク B25 として docs/tasks.md の B に積む。この ADR では実装しない。
7. 辞書の版（A3-3）とは切り離す。

## 13. 守りつきの上限を 10万 → 20万に広げる（2026-10-24。#283。承認済み）

### 13.1 現象
ユーザーの報告（2026-10-24）: こうようぶん が 紅葉分 で、公用文 が一発で出ない。辞書に 公用文（名詞,普通名詞,一般。コスト 16287）が 1 語で入っているが、**chiVe の順位が 194216 位**で、§2 の上限（10万）の外にあり、`frequent_compound` が当たらない。紅葉分（紅葉 2993 位 + 分）が 11 位まで負けていた。同じ型の 公用語（40643 位）、公文書（35966 位）は、すでに 1 位。

### 13.2 測った値（LM なし／あり。`COMPOUND_GUARDED_MAX_RANK` だけを変えた辞書を作り、同じバイナリで全セット 29 を流した）
基準は 10万の辞書（この作業用に作り直したもの。ABR の町字マスターが手元になく、地名の行を含まない。比べるのは同じ入力の辞書どうし）。

| 上限 | こうようぶん | 良くなった | 悪くなった（LM なし） |
| --- | --- | --- | --- |
| 10万（基準） | 公用文 11位 | | |
| **20万** | **公用文 1位** | せんこうぶんや 専攻分野 3位 → 1位（segments） | かいとうようしをくばる 解答用紙を配る 1位 → 9位（会東洋史を配る）、かいとうようし 解答用紙 2位 → 7位（segments。1位は 回答用氏 のまま） |
| 30万 | 公用文 1位 | 20万の分に加えて かえるかげんしょう 蛙化現象 40位 → 1位（new-words） | 20万と同じ |
| 上限なし | 公用文 1位 | 30万と同じ | 30万と同じ |

- **LM あり（締め切り 2000ms、全 29 セット）: 20万で変わったのは 公用文（紅葉文 5位 → 公用文 1位）だけ。悪化は 0。** LM なしの悪化 2 件（会東洋史）は LM が戻す。
- 悪化の原因は、20万位以内の まれな 1 語（会東洋史。かいとうようし の読みの辞書の行）が、解答 + 用紙 の分割に勝つこと。§0.2 の「まれな表記の熟語」と同じ型。守りは「同じ読みにもっと使う漢字の名詞がない」ことしか見ないので、2 語の分割の側が よく使う語どうしでも止められない。
- §2.2 の「20万でも既存のセットは同じ」は、当時のセットと辞書での値。今回は segments の 3 件が動いた（良くなった 1 件、悪くなった 2 件）。

### 13.3 決定（ユーザー承認、2026-10-24）
20万にする（LM なしの悪化 2 件は、LM ありでは 0。公用文、専攻分野 が直る）。30万以上は 蛙化現象 も直すが、当たる語がさらに増え、セットの外の効き方が読めないので採らない。
