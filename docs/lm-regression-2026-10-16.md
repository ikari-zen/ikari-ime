# LM を付けると悪くなる 33 件の調査（2026-10-16）

- 対象: main `67fd6d8`。AJIMEE を除く評価セット 2221 件。LM は zenz-v3.2 small、`--lm-budget-ms 2000 --lm-deadline-ms 2000`（時間切れ 0）。LM なし 1797、LM あり 1977（直る 213、悪くなる 33、正味 +180）。snapshot（[基準 main 2e9dbf5](accuracy-breakdown-2026-10-16.md)）と完全に一致した。
- 調査: architect（読み取りと評価の実行のみ。リポジトリは変更していない）。シミュレーションは、全 2221 件の候補ごとのスコア（LM なし、LM あり、辞書のコスト）を書き出して順位を付け直したもの。書き出しからの再現は、LM あり・なしとも 1 位が全件一致（同点 4 件は LM なしの順位で決着）。実際に流した alpha=0.5 とも一致した。**手段の得失は、実装して測ったものではなくシミュレーションの値**。
- 関連: [accuracy-breakdown-2026-10-16.md](accuracy-breakdown-2026-10-16.md)、[ADR 0003](adr/0003-topic-ranker-decision.md)、[ADR 0016](adr/0016-rare-homophones.md)。

## 1. 決定（ユーザー、2026-10-16）
- **(A) を進める**: 規則 S（サ変でない名詞＋する）が効いて守られている 1 位を、LM が覆さない。B40 として実装する（ADR 0024）。
- (B)（Ranker が決めた 1 位への上乗せ）は保留。全体の重み（alpha）は今のまま。
- 期待の確認（§5）は、あとで説明のうえ決める。
- モデルを足す・替える案（§6-3）は後回し。

## 3. 原因（測ったもの）
| 観点 | 結果 | 根拠 |
| --- | --- | --- |
| LM が文脈より頻度に引かれる | 文脈があった 21 件のうち **16 件は、文脈を外しても同じ誤りを選ぶ**（構成、対象、回答、関心、追求×2、用意、解放×2、成功、週末、想像、進行、完成、計った、代） | `zenz.context_chars=0`、`zenz.topic_words=0` との比較 |
| 文脈が逆に効くもの | 制作×2 と 温度計で計る は、文脈を入れたせいで誤る | 同上 |
| 文脈なしの入力 | 悪化 12/33（36%）、直る件は 47/213（22%）。LM が 1 位を変えた件のうち悪化の割合は、文脈なしで 20%、文脈ありで 11% | ケース別の比較 |
| 文脈そのものの価値 | LM から文脈を外すと全体は 1705（直る 83、悪化 175、正味 −92）。文脈は LM に不可欠 | 実測 |
| LM が話題などの Ranker を覆す | 悪化 33 件のうち 15 件は、辞書のコスト（base_cost）では負けていて、話題・左文脈・表記の Ranker のおかげで 1 位だった。LM がそれを辞書の順に戻した。直る 213 件でこの型は 18 件（195 件は辞書のコストの誤りを直した） | 書き出しの base_cost との比較 |
| LM が規則 S を覆す | #26〜29。LM なしの差 2472〜2896 が規則 S の +3000 の効果に当たり、LM の差 2639〜3783 がそれを上回った。LM の 1 位は 名詞,普通名詞,一般 + サ行変格する | CLI の分割 |
| LM の確信の強さ | L−m の中央値は悪化 898、直る 2589。ただし重なりが大きく、L−m ≤ 1000 は悪化 22、直る 43 | 書き出し |
| プール 32 件の打ち切り | 原因ではない（33 件とも正解は LM なしで 1 位、LM の 1 位は 5 位以内。max_candidates=8 で正味 157 に下がる） | 実測 |
| 加算の上限 6000 | 原因ではない（max_total=12000 で 214/33、正味 +1。上限に当たったのは #31 だけ） | 実測 |
| プロンプトの話題の語 | 効果は雑音の程度（`topic_words=0` で 215/34） | 実測 |

**確かめていないもの**: 期待の正しさ（判定は目視。`eval/sets/REVIEW.md` の ext の抜き取りは大半が未確認）、#3・#23・#24・#5 の型の規則ごとの内訳（ADR 0011・0017 を LM が覆した型と推定）、ほかのモデル。

## 5. 期待の確認（決定待ち）
悪化の 19 件（表記の流儀 8、文脈が足りず両方ありうる 11）は、期待そのものが一つに決まらない可能性がある。決まれば悪化から外れる。対象: 製作/制作、追究/追求、測る/計る、解答/回答、感心/関心、創造/想像、感性/完成、振興/進行、物の怪/もののけ、方/がた、最も/もっとも、こうかな/高価な、総計/早慶、常態化/状態か、台/代、製鋼/成功。

## 6. 残っていること
1. B40（(A)）の実装 → ADR 0024。
