ikari 0.1.0（macOS 版）の入れ方

【下書き・未確認】
この手順は、最初から最後まで通して確かめていません。
【未確認】の印がある所は、公開の前に実機で確かめて直します。

対応する環境: Apple Silicon の Mac、macOS 26.0 以上

このアプリには、Apple の開発者署名と公証がありません（未署名）。
公式の配布元は、GitHub の Releases だけです。
  https://github.com/ikari-zen/ikari-ime/releases

始める前に、下の「ダウンロードしたファイルの確かめ方」を行ってください。


■ 入れる 【未確認: この順番で通して確かめていません】

1. Finder で ⌘⇧G（「フォルダへ移動」）を押し、次を入力して開きます。
     ~/Library/Input Methods
2. ikari.app を、開いたフォルダへ移します（ドラッグします）。
3. ログアウトして、ログインし直します。
4. システム設定 → キーボード → 入力ソース → 編集 → ＋ → 日本語 から、
   「ikari」を追加します。【未確認: 画面の項目名】
   一覧に「ikari」が出ないときは、もう一度ログアウトしてログインします。
5. 入力ソースを「ikari」に切り替えます。


■ 初回の警告と許可 【未確認: 1 回の確認で見た内容です】

ikari に切り替えると、「"ikari" は開いていません」という警告が出ます
（ボタンは「ゴミ箱に入れる」と「完了」）。

1. 「完了」を押します。「ゴミ箱に入れる」は押さないでください。
2. システム設定 → プライバシーとセキュリティ を開きます。
3. 「このまま開く」を押して、許可します。

許可すると、変換できるようになります。
確かめたときは、ikari に含まれるほかの部品の追加の許可は出ませんでした。

警告を避けるために、macOS やウイルス対策ソフトの守りを切る必要は
ありません。そのような案内は ikari のものではありません。


■ 消し方 【未確認: 配布版で通して確かめていません】

学習の記録やユーザー辞書を残したいときは、先に「ikari 設定」
（入力メニューの「環境設定…」）の「学習とデータ」から
エクスポートしてください。

1. システム設定 → キーボード → 入力ソース → 編集 で、「ikari」を
   選んで「−」を押します。
2. ikari を使っていたアプリを閉じ、ログアウトしてログインし直します。
3. Finder の ⌘⇧G で ~/Library/Input Methods を開き、ikari.app を
   ゴミ箱に入れます。
4. 学習の記録、ユーザー辞書、ログも消すときは、次のフォルダを
   ゴミ箱に入れます。このフォルダを残せば、データは残ります。
     ~/Library/Application Support/ikari-ime
5. 次のフォルダが残っていれば、これも消せます。
     ~/Library/Containers/io.github.ikari-zen.inputmethod.ikari.engine
     ~/Library/Containers/io.github.ikari-zen.inputmethod.ikari.lm-cage


■ ダウンロードしたファイルの確かめ方

Releases のページの説明に、手順があります（SHA256SUMS、GitHub の
成果物の証明、作者の署名の 3 つ）。
  https://github.com/ikari-zen/ikari-ime/releases/tag/v0.1.0

1 つでも合わないときは、そのファイルを開かないでください。
