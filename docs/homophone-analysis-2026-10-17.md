## 0. 要点

1. 180 件のうち **12 件は、すでに期待を両方正解にした**（2026-10-16 のユーザー決定。[REVIEW.md](../eval/sets/REVIEW.md) の末尾）。残る 168 件を分けた。
2. 原因別（180 件）: (1) 文脈に決め手がない 48、(2) 期待が割れている 38（うち 12 は対応済み）、(3) 決め手はあるが LM が頻度に引かれる 54、(4) Ranker・規則が潰す 2、(5) 辞書・連接のコストの差が大きすぎる 38、(6) その他 0。
3. **決め手のある 94 件（(3)+(4)+(5)）のうち、正解はすべて LM のプールに入っている**（LM なしで 12 位以内。プールは 32 件）。LM の加算の上限（6000）を外しても L は全件同じ（上限は効いていない）。足りないのは「候補」ではなく「重み」。
4. (3) の 54 件では、**文脈は LM を正解の側へ動かしている（43 件）が、文脈なしでの LM の好み（頻度の事前分布）が勝つ**。文脈を強めた試し（10 件）と、読みを延ばした試し（15 件）でも、LM が直したのは約半分。
5. (5) の 38 件では、**LM（34 件）も話題などの Ranker（29 件）も正解の側に付いている**のに、辞書と連接のコストの差（中央値 4394。じき を除くと 3535）に届かない。うち 12 件は じき（時期 の経路のコストが 523、の のあとで −2326。次期・磁気 とは 9000〜10800 の差）。
6. シミュレーション: **LM の加点から「文脈なしでの LM の加点」を引く**（文脈があるときだけ。β=0.5〜0.75）と、13 セット 2221 件で 1 位が正味 **+21〜+31**（2000 → 2021〜2031）。ext-test でも +3〜+5（β は test を含めて選んだ）。一方、LM の重みを一律に上げる案は −21〜−25（シミュレーションの歪みを除いても −4〜−8）で、前の調査（lm-regression §4）と同じく使えない。**実装して測ったものではない**。
7. 直せる件数: 上限 94（決め手のあるもの）。見込みは、上の案で 168 件のうち 26〜41 件（決め手のあるもの 19〜27 件を含む）が直り、ほかで 10〜18 件崩れる。差し引き +21〜+31（全体の 0.9〜1.4 ポイント）。

### 4.1 (1) 文脈に決め手がない（48 件）
- 内訳: 短い文脈で両方とも自然 35（製品の＋しよう、未来を＋そうぞう、本社へ＋いどう、会社の＋こうしょう など）、文脈なし 6（さいかいする・して・しよう・さいかい、いとだけ、かんない）、文脈と期待の語順が不自然 5（社長・会長・首相の・監督に＋じき。次期 は前に置く語。最大＋こうしょう）、**期待の誤りの疑い 2**（校庭を地域住民に＋かいほう は 開放、ファッション＋しゅうかん は 週間 が自然）。
- 根拠: 人の判定（§2.2）。測った裏付けとして、文脈を外しても LM の好みが変わらない（L が Lnc 以上）ものが 21 / 48 件で、(3) の 11 / 54 件より多い。LM が使える手がかりが文脈に少ない。
- 直すべきでない。どちらかに寄せると、もう一方を打った人が困る（基本原則「入力を正とする」。個人の好みは学習で合わせる範囲）。

### 4.2 (2) 期待が割れている（未対応 26 件）
- 内訳: はかる 12（量る / 計る / 測る。公用文の異字同訓の使い分けでは、重さは 量る、長さは 測る、時間は 計る）、追究 / 追求・追及 8、意志 / 意思 2、治める / 収める 2（怒りを は 収める のほうが一般的）、保障 / 保証 1（安全を）、制作 / 製作 1（自主映画の）。
- 根拠: 辞書の差がほぼ 0（中央値 521、異字同訓は −139〜139）で、LM が一人で決めている。昨日ユーザーが両方正解にした 19 件と同じ型。
- 期待の扱いを決めれば評価の外れから外れる。変換は変わらない。

### 4.3 (3) 決め手はあるが LM が頻度に引かれる（54 件）
- 例: ゲラの＋こうせい は 構成（正解 校正）、点＋たいしょう は 対象（対称）、決して＋ようい は 用意（容易）、怪我人を＋かいほう は 解放（介抱）、世界の＋しゅうまつ は 週末（終末）、新入社員は、三か月間は＋しよう は 使用（試用）、スタンドから＋かんせい は 完成（歓声）。
- 根拠（測定）:
  - LM の加点の差 L は全件が正（W を好む）。文脈なしの LM の好み Lnc の中央値 2659 に対し、文脈ありは 1493。**43 / 54 件で、文脈は LM を正解の側へ動かしている**が足りない。残る 11 件は文脈がかえって W に寄せる（ゲラの、どちらにも偏らない、機能の追加に合わせて、条件を変えない群を置いて、民間、夕暮れの、スタンドから、在庫を、子ども向けの、駅の売店で、本の発売日が近づき…最後の）。
  - **6 件は LM なしなら正解だった**（LM の悪化。lm-regression の「頻度に引かれる 16 件」と重なる）: ゲラの 校正、点 対称、決して 容易、怪我人を 介抱（2 セット）、世界の 終末。
  - 実験 (e)（§5）: 文脈を強めても、読みを延ばしても、LM が直すのは約半分。
- 今の zenz small の性質（lm-regression §3 と同じ結論）。ただし §6 のとおり、LM の事前の好みを差し引けば、モデルを替えずに一部は直る。

### 4.4 (4) Ranker・規則が潰す（2 件）
- 論文を＋きこう は 聞こう（正解 寄稿）: 左文脈の段（ranker doc の構成）で 聞こう が −6000（を から動詞への連接の増幅。LeftContextRanker、ADR 0002 §22）。LM は 寄稿 を推す（L −1029）が届かない。
- 障害物＋きょうそう は 競争（競走）: 同じ段で 競争 が −9000。LM の上限 6000 では覆らない。左文脈の複合語の加点（ADR 0007）と推定（どの規則かは切り分けていない）。
- どちらも文法・複合語の規則が意図どおり働いた結果の副作用で、型としては小さい。直さない。

### 4.5 (5) 辞書・連接のコストの差が大きすぎる（38 件）
- 例: 時期 と 次期・磁気 12（地球の、カードの、OSの、選挙で など）、使用 と 仕様 5（バグではなく、もともとの など）、構成 と 公正・更生 4、効果・高価 と 硬貨 3、完成 と 歓声・感性 3、ほかに 用意 と 容易、正確 と 性格、移動 と 異動、医師 と 意思・意志、高低 と 校庭、受容 と 需要、部隊 と 舞台、糸だけ と 意図だけ。

### 8.1 案 1 の懸念（ADR で決めること）
- **応答時間**: 採点が 2 回になる。ただし、文脈なしの採点は読みと候補だけで決まり、文脈に依らないので、読みをキーにした小さなキャッシュで使い回せる（同じ読みを何度も打つ）。外れたときは LM の時間が約 2 倍になり、ADR 0021 の「約 87% が間に合う」が下がりうる。先行計算（打っている間）に文脈なしの採点を先に済ませる形が考えられる。
- **崩れる型**: 短い文脈（1 語）のあとの 1 文字の語、助数詞、異字同訓（§6 の崩れる 18 件）。文脈の長さや候補の長さで β を効かせない条件を付けると減らせる見込みだが、条件は dev で選び test で確かめる必要がある。
- **学習と最後の段**: 学習（ADR 0013）は LM の前にあり、LM の変更が学習を覆す量が変わる。B32（英字の規則）、B40（規則 S）は LM の後なので影響しないはずだが、スパイクで確かめる。
- **基本原則**: 候補は辞書のまま、LM は並べ替えだけ（守る決定どおり）。読みに対応しない候補は増えない。
