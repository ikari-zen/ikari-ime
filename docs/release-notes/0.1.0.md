# ikari 0.1.0（macOS 版）

ikari は、前後の文脈に応じて同音異義語を選び分ける、日本語の入力メソッドです。これが最初の配布版です。

短く確定しながら書くことを前提にしています。入力していない文字を補う機能（予測変換など）はありません。

## このリリースの内容

- **文脈つきの変換**: 直前に確定した語や入力欄の周りの文章を手がかりに、候補を並べ替えます。表記の既定は公用文の書き表し方に沿います。確信が高いときは、最初の Space で 1 位の候補だけを下線つきで出します（設定で止められます。もう一度 Space か ↓ で一覧が出ます）。
- **文節の編集と再変換**: ←/→ で文節を選び、Shift+←/→ で区切りを直せます。確定した文字も変換し直せます。
- **入力方式**: ローマ字入力と JIS かな入力。キー操作は macOS 風・MS-IME 風・ATOK 風から選び、個別に変えられます。
- **英語のモード**: 打ったキーをそのままアプリに渡します。
- **ユーザー辞書と学習**: 単語を登録できます。学習は候補の順番を助けるもので、候補を決め打ちしません。消去、エクスポート、インポートができます。
- **小型の日本語モデルによる並べ替え**: モデル `zenz-v3.2-small` を使います。処理は Mac の中で行い、設定でオフにできます。
- **そのほかの候補**: 日付、和暦、四則演算、住所と郵便番号、絵文字（`:eyes:` の形。既定はオフ）など。
- **設定アプリ「ikari 設定」**

## 対応する環境

- Apple Silicon の Mac（Intel の Mac では使えません）
- macOS 26.0 以上

## 入れ方

このアプリには、Apple の開発者署名と公証がありません（未署名）。そのため、初回に macOS の警告が出ます。

## ダウンロードしたファイルの確かめ方

公式の配布元は、この GitHub の Releases だけです。ファイルを開く前に確かめてください。コマンドは「ターミナル」で、ダウンロードしたフォルダに移動してから実行します。

**1. SHA-256 の値**（このページから `SHA256SUMS` も取ります）

```sh
shasum -a 256 --ignore-missing -c SHA256SUMS
```

ダウンロードした dmg の行が `OK` になることを確かめます。

**2. 作られた経過の証明**（GitHub CLI の `gh` が必要です）

```sh
gh attestation verify <ダウンロードした dmg のファイル名> -R ikari-zen/ikari-ime
```

**3. 作者の署名**（`minisign` が必要です。このページから `SHA256SUMS.minisig` も取ります）

```sh
minisign -Vm SHA256SUMS -P <作者の公開鍵>
```

作者の公開鍵: （未定）

**1 つでも失敗したら、そのファイルは開かないでください。** 公開の Issue には書かず、[SECURITY.md](https://github.com/ikari-zen/ikari-ime/blob/v0.1.0/SECURITY.md) の方法で非公開で知らせてください。ウイルス対策ソフトに検出されたときは、[誤検出の案内](https://github.com/ikari-zen/ikari-ime/blob/v0.1.0/docs/antivirus-false-positive.md)を見てください。

## セキュリティの約束

入力メソッドは、打ったキーのすべてを受け取るソフトです。ikari が約束することと、約束できないことは [SECURITY.md](https://github.com/ikari-zen/ikari-ime/blob/v0.1.0/SECURITY.md) にまとめています。使う前に読んでください。

約束できないことの例: ikari はあなたが書き換えられるフォルダ（`~/Library/Input Methods`）に置くため、同じユーザーで動く別のプログラムは、ikari を差し替えられます。
