# ikari-ime 文章の取り込みプロンプト（ingest-prompt-v1）

プロンプトの版: `ingest-prompt-v1`（出力ファイルのヘッダの `prompt_version` に、この版をそのまま書くこと）

> **注意（業務文書を送らないでください）**
> このプロンプトと一緒に、勤務先の業務文書、顧客情報、機密情報、個人情報を含む文章をクラウドの LLM に入力しないでください。
> 取り込みでクラウドの LLM を使うのは、あなた自身の操作です。入力してよいのは、あなた自身が書いた、外部に出してよい文章（個人のブログ、メモ、創作など）だけにしてください。
> 迷う場合は入力せず、手元で動かす LLM を使うか、取り込みをやめてください。

## あなたの役割

私が貼り付ける文章を、**1文ずつ**、「表記」と「読み」の組にして、JSON Lines（1行に1つの JSON）で出力してください。
日本語入力（IME）の初期学習データにします。要約、翻訳、言い換え、誤字の修正はしないでください。

## 出力の形式

出力は JSON Lines だけにしてください。説明文、前置き、あと書きは書かないでください。
コードブロック（` ``` `）で囲まなくてかまいません。囲んでも読み込めます。

1行目は必ず次のヘッダにします（文字は変えない）。

```
{"type":"header","format":"ikari-ingest","version":1,"prompt_version":"ingest-prompt-v1"}
```

2行目以降は、次の2種類の行だけを使います。

- 文: `{"type":"sentence","surface":"<原文の1文>","reading":"<その読み>"}`
- 文書の区切り: `{"type":"doc_break"}`（別の文書や、話題が大きく変わる所に1行入れる）

例:

```
{"type":"header","format":"ikari-ingest","version":1,"prompt_version":"ingest-prompt-v1"}
{"type":"sentence","surface":"ユーザー辞書に単語を登録するときは品詞を指定する。","reading":"ゆーざーじしょにたんごをとうろくするときはひんしをしていする。"}
{"type":"sentence","surface":"その話を初めて知った。","reading":"そのはなしをはじめてしった。"}
{"type":"doc_break"}
```

## 表記（surface）の決まり

- 原文の1文を、そのまま書く。文末の句点（。！？）まで含める。1文は400文字以内。長い文は、読点の所で2つに分けてよい。
- **除外するもの**（出力に含めない）:
  - Markdown のコードブロック（``` で囲まれた部分、インデントされたコード）
  - インラインコード（`で囲まれた部分）。その文の中にあれば、その文ごと出力しない
  - URL、メールアドレス、ファイルパス
  - 表、見出しの記号だけの行、箇条書きの記号（`-` や `*`）。文の本体は残す
- 固有名詞、製品名、社内用語も原文のまま書く。伏せ字にしたり、置き換えたりしない。

## 読み（reading）の決まり

- ひらがなで書く。長音は「ー」を使う（例: ゆーざー）。
- 漢字、カタカナ語はすべてひらがなにする。「は」「へ」「を」は発音ではなく、**表記どおり**に書く（例: 「私は行く」→「わたしはいく」。「わたしわいく」にはしない）。
- 表記に含まれる英数字と記号（`。` `、` `A` `3` など）は、読みにも**同じ文字でそのまま**書く。英単語や数字をひらがなにしない（例: 「APIを呼ぶ」→「APIをよぶ」）。
- 読みが分からない語は、無理に推測せず、その文を出力しない。
